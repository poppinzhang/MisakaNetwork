# LastOrder 外观主题

LastOrder 在 Windows、macOS 和 Android 上共用浅色／深色主题实现。首次启动默认「跟随系统」；主界面顶部的外观菜单可选择「跟随系统」「浅色」「深色」，桌面和手机布局均提供入口。

## 切换与持久化

- 跟随系统时，系统外观改变会更新应用主题，无需重启；手动选择浅色或深色后，系统外观变化不会覆盖该选择。
- `SavedState.themeMode` 使用 `AppThemeMode` 枚举，保存到应用私有目录的 `state-v2.json`，字段为 `theme_mode`，取值为 `system`、`light` 或 `dark`。
- 缺少字段或字段值无法识别时使用 `system`。该设置不包含凭据，不写入钥匙串，也不改变现有账号、机器和任务数据。
- `AppController.setThemeMode` 通过现有状态保存队列提交变更，保存成功后通知界面更新。写入失败会保留原模式并显示错误；配置尚未加载时不能保存主题选择。
- 机器、账号、任务的后续保存保留当前主题；重新启动后读取已保存的选择。

## 界面与平台边界

浅色和深色主题统一使用 `material_ui` 的 Material 3 主题。页面背景、卡片、输入框、文字、状态提示和弹窗均按当前主题配色，交互图标继续使用 Lucide。

Android 的系统状态栏和导航栏图标亮度随应用主题调整。Android 16 / API 36 使用边到边窗口，内容背景负责系统栏区域的底色；原生启动窗口使用已配置的系统浅色／深色资源，Flutter 加载设置后采用应用所选主题。

Windows 和 macOS 由 Flutter 接收系统亮度变化；桌面原生标题栏等系统窗口装饰仍遵循操作系统外观设置。该功能无需更改运行时、Sisters 或通信协议。

## 验证与交付

主题测试覆盖默认跟随系统、系统亮度变化、手动覆盖、模式持久化、错误处理以及桌面和手机入口。常规验证命令和完整应用打包要求见根目录 `AGENTS.md` 与 [打包与发布](../打包与发布.md)。

本轮源码验证：`flutter analyze` 无问题，`flutter test` 全部 120 项通过，其中新增 19 项主题相关测试（8 项偏好与并发保存、1 项本地文件恢复、10 项界面与系统栏测试）。平台亮度测试使用 Flutter 测试环境模拟 Windows、macOS、Android。

本功能随 0.2.0 发布。源码测试使用模拟平台亮度，不代表原生设备验收；各平台完整包与原生验证的实际结果见 [0.2.0 交付记录](../releases/0.2.0.md)。
