# 腾讯云 CVM 基本流程（未发布）

本轮实现腾讯云普通按量计费实例的安全组准备、公钥导入、创建、查询与释放。源码功能尚未发布，不代表现有 0.2.3 安装包已经支持，也不代表真实账号权限、云资源、费用或抢票业务已验收。阿里云与火山引擎仍是本地交互预览。

## 使用流程与边界

1. 管理员填写 `LastOrder/assets/cloud_templates/tencent.json` 后重新构建完整应用。仓库默认是空模板集合，腾讯云页面不会提供虚假的可购买配置。
2. 在「公有云部署」保存腾讯云 SecretId、SecretKey。保存只检查本地格式；云端鉴权和权限检查在实际操作时进行。
3. 从「添加机器 → 云服务器创建 → 腾讯云」选择已打包模板，核对地域、规格、系统盘、SSH 与 20001 端口的允许来源，确认创建按量实例。余额、配额、库存与实际价格以腾讯云为准。
4. LastOrder 先保存操作意图，再准备安全组和 SSH 公钥，提交一次购买请求，轮询云端状态。实例运行后显示「已创建 · 待部署」及实例 ID、公网地址。本轮不自动执行 SSH 部署、不进入 Sisters 任务分发列表，不把云服务器运行中当作 Sisters 可用。
5. 需要停止使用时，从该实例卡片确认「释放云服务器」。释放会中断服务器上的任务并销毁系统盘数据；只有后续查询确认终态或精确实例不存在才显示已释放。关闭应用不释放资源、不保证停止计费。

自动部署需要后续衔接现有 SSH 主机指纹核对、离线部署、linger 检查和 mTLS 可达性验证。本轮不关闭或替代这些检查，也不改动 biliTickerBuy 运行时。

## 模板与打包

固定入口为 `LastOrder/assets/cloud_templates/tencent.json`，顶层格式为 `{"schemaVersion":1,"templates":[]}`。字段、限制与脱敏示例见[模板目录说明](../../LastOrder/assets/cloud_templates/README.md)。支持多套模板，模板 ID 必须唯一；读取失败时禁止创建，不回退到演示配置。

模板指定地域、可用区、实例类型、公共 Ubuntu 24.04 镜像、x64/arm64、系统盘、已有 VPC/子网、按流量后付费公网带宽，以及 IPv4 来源网段。CPU、内存是管理员维护的展示信息，须与实际机型一致。创建前还会核对镜像的系统、架构、状态与最小系统盘大小。模板不保存云凭据或 SSH 私钥，不接受任意 API 参数、启动脚本、额外数据盘、竞价、包年包月或独立 EIP。

购买层固定 `InstanceChargeType=POSTPAID_BY_HOUR`、`InstanceCount=1`，应用生成登录密钥、安全组、操作标签和幂等 token；这些字段不能由模板覆盖。模板公网方式固定为 `TRAFFIC_POSTPAID_BY_HOUR`，不设置预付费公网带宽。

资源已在 `pubspec.yaml` 声明，标准 Flutter assets 构建会将 JSON 打进 Windows、macOS、Android；完整应用仍须按[打包与发布](../打包与发布.md)构建。替换模板后必须重新打包，已创建实例保留当时模板快照。不要将个人网络 ID、地址、账号环境信息或凭据提交进公共仓库；管理员的实际模板仅用于所需的本地构建。

管理员填写网页是仓库外的独立本地工具，不属于 LastOrder、不进入源码或发布包。本机服务只接受来自自身页面的操作，将校验后的整个模板集合原子保存到上述固定文件，不提供任意路径写入。

填写工具提供联动选项。地域/可用区首先使用官方文档参考快照（标明核查日期和特殊售卖说明，不表示账号当前可购买）；用户可在网页临时输入 SecretId/SecretKey，再主动查询实时地域、可用区、按量可售机型、兼容 Ubuntu 24.04 官方镜像，以及账号内已有 VPC/子网。选择机型带回 CPU/内存，选择镜像带回架构与最小系统盘容量；切换上游配置会清理依赖选项。也保留手工填写入口和每个字段的官方说明。

机型代码按官方返回值保留大小写。[官方实例规格](https://cloud.tencent.com/document/product/213/11518) 包含 `S5se.LARGE16`、`S9pro.MEDIUM4` 等混合大小写的实例族；查询响应、镜像查询入参、模板保存及 Go/Dart 模板解析采用一致格式，不能将机型限制为全大写或自动转成大写。加载按钮旁显示前置条件错误、查询状态和空列表；镜像查询需要先选中机型，标识格式异常会指出对应资源类别，不回显原始响应。

管理员查询工具仅允许固定的 Describe 接口，不包含购买、创建网络或释放接口。密钥通过本机页面送到本机服务，服务对固定腾讯云 HTTPS 端点签名查询；密钥不写模板、普通文件或日志，不读取 LastOrder 安全存储。刷新页面或主动清除临时凭据后需重新输入；云端权限不足、网络失败与真实空列表分别提示。网页查询结果是查询时点的参考，不能保证后续购买时仍有库存或余额。

| 字段 | 含义与官方查询方式 |
| --- | --- |
| 地域 / 可用区 | 地域是地理区域；可用区是区域内独立机房。参考[地域和可用区](https://cloud.tencent.com/document/product/213/6091)，实时查询采用地域管理系统的 [DescribeRegions](https://cloud.tencent.com/document/product/1596/77930) / [DescribeZones](https://cloud.tencent.com/document/product/1596/77929)，产品固定为 CVM。 |
| 机型 | 不是固定通用枚举。按可用区与 `POSTPAID_BY_HOUR` 查询 [DescribeZoneInstanceConfigInfos](https://cloud.tencent.com/document/api/213/17378)，只展示接口报告可售的规格。 |
| 镜像 ID | 指具体系统镜像；按地域与选定机型查询 [DescribeImages](https://cloud.tencent.com/document/api/213/15715)，再筛选正常状态的 Ubuntu 24.04 官方公共镜像。 |
| VPC / 子网 | 属于用户账号的已有网络资源，没有跨账号通用 ID；查询 [DescribeVpcs](https://cloud.tencent.com/document/api/215/15778) / [DescribeSubnets](https://cloud.tencent.com/document/api/215/15784)，子网与所选 VPC、可用区对应。 |

工具额外需要 `region:DescribeRegions`、`region:DescribeZones`、`cvm:DescribeZoneInstanceConfigInfos`、`cvm:DescribeImages`、`vpc:DescribeVpcs`、`vpc:DescribeSubnets` 的查询权限。这些是管理员工具的权限范围，不是新增购买授权；实际授权资源范围以腾讯云当前 CAM 文档为准。

## 安全组、公钥与通信

安全组使用固定项目前缀和来源规则摘要形成稳定名称，按地域查询并复用。入站仅允许模板给定来源访问 TCP 22 与 TCP 20001，出站允许正常联网；使用更广的来源需管理员明确填写。相同名称的组必须符合本项目归属和预期策略，不静默改写已有组来扩大访问范围。应用内串行准备以减少重复创建；多个独立客户端同时首次创建仍受云端接口的并发语义约束，不能承诺全账号唯一。

首次启动生成的 RSA 2048 SSH 身份继续保存在系统安全存储；只把公钥导入腾讯云，按公钥内容生成稳定名称并核对已有公钥，不上传私钥。安全组、登录公钥、VPC 和子网是复用资源，释放单个实例不删除它们。

腾讯云 API 在控制端 Go helper 中调用：桌面使用标准输入辅助进程，Android 复用原生桥接。不使用环境变量、命令行参数或普通文件传递密钥，不将管理云资源的权限交给 Sisters。固定腾讯云 HTTPS 域名、保留证书链和域名校验、禁止跟随重定向；TC3 签名由封闭的标准库适配器实现，不增加云 SDK 依赖。上游原始错误消息和请求体不进入界面或日志。

## 状态持久化与异常恢复

云账号与资源记录保存在独立系统安全存储条目；持久化地域、创建时 SecretId 关联、模板快照、操作 UUID、稳定 ClientToken、安全组/公钥 ID、实例 ID、云端请求 ID 与进度。未释放或创建结果待核实的实例阻止删除本地记录、移除凭据或换成其他 SecretId；同一 SecretId 可以更新 SecretKey。

购买前先保存请求意图。创建响应丢失时显示「创建结果待核实」，查询按操作标签找回精确实例；不重新调用 RunInstances，不自动换 token 再次购买。查询没有结果不能证明没有创建，仍须在腾讯云控制台核对。创建准备失败、且确认未提交购买的记录可以移除；准备阶段已生成的共享组和公钥会保留以供复用。

应用重启恢复查询，不重新购买、不自动销毁。释放请求仅针对本地记录的精确实例，并核验项目标签、操作 token 与按量计费类型。额外数据盘、独立 EIP 等超出本轮管理范围的资源会阻止自动释放，交由用户在控制台处理；不会因为关联到实例就擅自删除。释放 API 返回请求 ID 只是受理，查询失败、超时或权限不足均保留记录与费用提示。

实例 ID 返回后本地保存失败时，在内存保留 ID 和错误；重启依靠此前已持久化的 token 查询恢复。没有实例 ID 的未知记录无法直接销毁，须先找回实例或去控制台核实。自动查询最多 60 轮，每轮查询结束后间隔 5 秒（不含请求耗时），之后转为人工刷新；Android 后台或应用退出不保证持续查询。

## CAM 权限与官方依据

专用 CAM 子用户按实际地域和资源限制权限，不要求主账号密钥。当前适配器使用以下操作：

- CVM：`DescribeImages`、`DescribeKeyPairs`、`ImportKeyPair`、`RunInstances`、`DescribeInstances`、`TerminateInstances`。
- VPC：`DescribeSecurityGroups`、`CreateSecurityGroup`、`DescribeSecurityGroupPolicies`、`CreateSecurityGroupPolicies`、`DescribeAddresses`。
- 创建操作涉及标签绑定，需按腾讯云当前资源授权规则授予关联权限；不能仅凭凭据保存成功认定权限齐全。

核查日期：2026-11-13。官方接口依据：[RunInstances](https://cloud.tencent.com/document/api/213/15730)、[DescribeInstances](https://cloud.tencent.com/document/api/213/15728)、[TerminateInstances](https://cloud.tencent.com/document/api/213/15723)、[CreateSecurityGroup](https://cloud.tencent.com/document/api/215/15806)、[TC3 签名](https://cloud.tencent.com/document/api/213/30654)。字段与云端行为会变化，升级适配器时重新核查并补充离线回归。
