# 火山引擎 ECS 接入（未发布）

源码接入火山引擎按量 ECS 的共享网络、安全组、公钥准备、实例创建、查询、内置密钥部署与释放。模板由管理员填写，默认空集合；现有公开 0.2.3 安装包不包含此功能。本轮不购买真实资源，不代表实账号权限、库存、SSH、费用或业务验收。

## 使用与模板

1. 管理员使用仓库外的本地模板网页维护 `LastOrder/assets/cloud_templates/volcengine.json`，再构建完整应用。网页不进入项目或安装包，云密钥不写进模板。
2. 在「公有云部署」填写火山引擎 IAM 的 Access Key ID 和 Secret Access Key，经官方 STS 身份查询成功后保存。不是火山方舟的模型 API Key；身份成功不证明资源操作权限、余额或配额。
3. 从「添加机器 → 云服务器创建 → 火山引擎」选择配置并确认创建。每次创建一台按量服务器及配套按流量计费 EIP，都会产生云费用。
4. 应用先记录意图，准备地域共享 VPC、可用区子网、安全组和公钥，再创建实例。优先使用建议可用区，只有云端明确拒绝且属于库存不足时才按下节规则回退。创建响应不确定时只查询恢复，不重新购买；重启不自动重试创建。
5. 出现「已创建 · 待部署」后点击「部署 Sisters」，复用安全存储中的 SSH 私钥及离线包。火山引擎 Linux 默认登录账号为 `root`，本路径不套用腾讯云的 `ubuntu` 或其专用 sudo linger 参数。首次主机指纹自动保存，之后严格校验；TOFU 不能提供首次连接的独立身份认证。应用不会自动分发任务。
6. 停止使用时点击「释放云服务器」。此操作删除实例、系统盘及本次创建的 EIP，中断任务；共享网络、安全组及公钥保留。只有实例与记录的 EIP 都确认不存在后，才移除卡片及其分发候选；任务历史与订单关联保留。关闭应用不保证停止计费。

模板顶层是 `{"schemaVersion":2,"templates":[]}`。每项展示字段与腾讯云一致：`id`、`name`、`description`、`cpu`、`memoryGb`、`diskGb`、`architecture`、`os`、`sshUsername`、`regionLabel`、`region`。`os` 是管理员填写的系统显示名，`sshUsername` 是实际密钥登录账号。配置白名单：

| 字段 | 约束 |
| --- | --- |
| `runInstances.ZoneId` | 模板地域内的建议可用区；国内如 `cn-beijing-a`，海外如 `ap-southeast-1a`；明确库存不足时按相同规格自动尝试同地域其他可用区 |
| `runInstances.InstanceTypeId` | 火山引擎规格标识；CPU/内存由管理员与实际规格核对 |
| `runInstances.ImageId` | 管理员选择的镜像，不限 Linux 发行版、Ubuntu 版本或来源；创建前核对 Linux 类型、可用状态、架构与最小系统盘 |
| `runInstances.Volumes` | 恰好一个系统盘：`VolumeType` 为 `ESSD_PL0` 或 `ESSD_FlexPL`；`Size` 为 20–2048 GiB，须等于 `diskGb` |
| `runInstances.EipAddress` | `ISP=BGP`、`ChargeType=PayByTraffic`、`BandwidthMbps=1–200`、`ReleaseWithInstance=true` |

地域和可用区使用火山自身的命名规则，不能照搬腾讯云：例如 `ap-southeast-1` 对应 `ap-southeast-1a`，字母前没有额外连字符。[官方地域与可用区](https://docs.volcengine.com/docs/ecs/regions-and-availability-zones?lang=zh)

运行层固定 `InstanceChargeType=PostPaid`、`Count=1`、系统盘 `DeleteWithInstance=true`；注入独立的创建 token、归属标签、共享网络、安全组及登录公钥。模板不能覆盖密钥、密码、UserData、端点、资源 ID 或任意云 API 参数，不接受数据盘、预付费或竞价。SSH TCP 22 和 Sisters TCP 20001 来源固定为 `0.0.0.0/0`，出站允许正常联网。

模板以 Flutter asset 打包，三端使用相同资源。修改模板需重新构建完整应用；已有实例保留创建时快照。没有旧火山真实资源格式需要迁移；已有本地预览记录仍只是演示。源码没有新增版本号或交付安装包。

## 同地域可用区回退

模板 `runInstances.ZoneId` 为建议可用区，首先按该区准备子网并购买。只有本次 `RunInstances` 返回可确认的容量拒绝，才调用 `DescribeAvailableResource` 查询同地域候选区；目前仅接受官方明确记录的 `Insufficient.InstanceCapacity` 与 `Insufficient.VolumePoolCapacity` 两种错误。响应必须具备匹配的操作、版本、地域、服务与请求标识，且不能同时含成功结果或实例 ID；其他错误与异常返回均不作为换区依据。[官方创建错误码](https://docs.volcengine.com/docs/ecs/runinstances-createsinstances?lang=en)

库存查询固定 `DestinationResource=InstanceType`、原模板的 `InstanceTypeId` 与 `InstanceChargeType=PostPaid`，不指定 `ZoneId`。只接受返回地域一致、可用区格式正确，且可用区和该**精确机型**均为 `Available` 的条目；可用区中有其他规格可售不足以构成候选。重复结果保守合并，有冲突时排除；候选去重排序，并跳过已尝试可用区，每区最多尝试一次。查询时可售不保证购买时仍有库存。[官方库存查询](https://docs.volcengine.com/docs/ecs/describeavailableresource?lang=zh)

回退仅改变执行快照中的 `ZoneId` 和对应子网。地域、实例规格、CPU/内存展示、架构、镜像、系统盘类型与容量、EIP 带宽与计费、EIP 随实例释放策略、单实例数量、安全组、公钥以及普通按量计费保持不变；不跨地域，不升级或降配。原模板保留建议区，资源记录另存选定区及已明确拒绝的可用区。

每轮必须先持久化上一次明确拒绝，才选择下一可用区。切换后生成并保存独立购买 token，按该区准备/复用子网，再保存实际网络 ID 和提交意图，最后发送创建请求。同一个 token 不用于不同可用区；任何保存失败立即停止，不继续购买。

全部候选区售罄、无候选区、库存查询失败、网络准备失败均停止并保留可核对的记录。余额、权限、配额、其他参数拒绝、`InternalError`、超时、断线、响应丢失或格式矛盾不会触发回退；提交结果未知时保留最后一轮 token，只按该操作查询恢复，即使暂时查不到实例也不能重新购买。应用重启不会自动继续创建。明确失败且尚未提交新一轮购买的记录可由用户主动重试准备，仍跳过已明确拒绝的可用区。

额外需要 `ecs:DescribeAvailableResource` 的查询权限；实例创建及关联资源权限不变。换区前已准备的共享子网仍保留，不随实例释放。模板格式保持 1，已有模板无需改字段；需重新构建包含此源码的完整应用才会启用本行为。

## 实例与 EIP 一同释放

火山引擎的关联删除开关在**创建参数**中：`RunInstances.EipAddress.ReleaseWithInstance=true`，仅适用于按量 EIP；默认值是 false。`DeleteInstances` 本身没有另一个同名删除参数，因此不能等到释放时才依赖默认值。[官方创建参数](https://docs.volcengine.com/docs/ecs/runinstances-createsinstances?lang=zh)

应用记录实例查询返回的 `EipAddress.AllocationId`。发起删除前，先持久化该 EIP ID 与释放意图，再核验精确实例及归属。`DeleteInstances` 的 HTTP 成功不等于每台操作成功，还需核对 `OperationDetails` 中对应实例的错误。请求失败、响应丢失、EIP 未确认或查询失败，均保留记录和凭证保护。[官方删除接口](https://docs.volcengine.com/docs/ecs/deleteinstances-deletesinstances?lang=en)

释放后分别查询实例和 EIP：实例不在了、EIP 仍存在时显示释放待核实，不报告完成；查询缺字段或格式异常不作为不存在。EIP 更换、未知关联或归属不明时停止，不自动释放外部绑定的 EIP。若关联删除未完成，应在火山引擎控制台核对并处理记录中的资源，再返回应用重新查询；应用不对不明附属资源进行宽泛清理。[官方实例查询](https://docs.volcengine.com/docs/ecs/describeinstances?lang=en)、[官方 EIP 查询](https://docs.volcengine.com/docs/elastic-ip-address/describe-eip-addresses-querying-eip-s?lang=en)

实例与 EIP 都确认不存在才能清除活动视图。没有已记录 EIP ID、没有可确认释放结果或仅收到删除受理响应时均不能推断费用归零；账单、手动附加磁盘和快照仍需在云平台核对。

## 共享资源与异常恢复

### 创建准备失败的诊断

准备失败卡片显示「尚未提交购买」时，表示本轮没有发送实例购买请求；已准备的共享资源仍保留。源码现在区分共享 VPC 准备、共享子网准备；后续准备进一步区分 SSH 公钥检查、镜像检查、共享 VPC 复核、SSH 公钥准备与安全组准备，并显示内置辅助程序的固定脱敏原因，例如镜像不可访问、身份或权限校验失败、密钥指纹不匹配或安全组规则冲突。处理提示中的原因后，可在原记录点击「重试准备并创建」。旧包的通用提示不能用于确定实际失败原因，更新不会从旧记录还原已经丢弃的错误；需主动重试才会记录新的诊断。

辅助程序与界面都只接受固定阶段和精确匹配的固定原因；界面仅在准备调用中识别组合，不将其他厂商或网络创建/购买错误重新分类。资源列表异常进一步区分字段缺失、列表格式错误与分页不完整。未知辅助程序错误只保留固定阶段与通用原因，不输出异常原文。仅精确匹配代码中列出的固定错误文本；带附加内容、未知异常或任意上游消息仍使用通用提示，不把云密钥、请求内容或原始日志写入卡片和存储。共享网络已有创建意图但结果待核实时，仍优先显示查询恢复提示；实例购买提交后仍保留未知状态，不能因具体错误类别而重新购买。此修改只改善诊断，不放宽云资源归属、镜像、安全组、TLS 或释放确认校验。

网络失败进一步按 Go 错误类型及包装链分类：DNS、超时、TLS 证书链/有效性、TLS 域名、系统网络权限、连接拒绝、不可达、中断、取消及未知错误。提示由本地固定文案生成，不匹配或展示任意错误原文；Windows 同时识别 Winsock 的对应错误码。查询失败不等于 VPC 不存在；网络状态仍未知时不会继续购买或删除记录。

根据「共享 VPC 准备：火山引擎拒绝了资源参数」的新提示继续核查，确认原客户端统一发送 POST 表单，而 [VPC 请求结构](https://docs.volcengine.com/docs/virtual-private-cloud/request-structure?lang=zh)明确只支持 GET。源码已将整个 VPC 服务改为 GET，包含子网、安全组与 EIP 查询；参数进入查询串并参与签名。[ECS 请求结构](https://docs.volcengine.com/docs/ecs/request-structure?lang=zh)同时支持 GET 与 POST 表单，因此 ECS 继续使用 POST。无需为此修改原模板、分页或重新录入凭证；更新包含修复的完整应用后，在原失败记录重试。接口错误已由官方契约与离线测试确认，真实云端创建仍需验证。

### 共享资源保留与恢复

VPC 使用固定专用网段 `10.8.0.0/16`，子网分配不重叠 `/24`；按账号、厂商、地域及可用区隔离共享网络账本。先保存创建意图，再调用 API，返回实际 ID 后保存并等待查询可见。超时或应用退出保留待核实意图，只读查询恢复；同名冲突或归属不匹配停止，不接管其他网络。多个独立客户端的创建不具有跨客户端锁保证。

准备阶段的五种列表（`Vpcs`、`Subnets`、`Images`、`KeyPairs`、`SecurityGroups`）按精确服务、操作和字段名允许显式 `null` 与 `[]` 表示空页。VPC、[子网](https://docs.volcengine.com/docs/virtual-private-cloud/describe-subnets-queryingasubnetlist?lang=zh)及[安全组](https://docs.volcengine.com/docs/VirtualPrivateCloud/DescribeSecurityGroups-Queryingasecuritygrouplist?lang=en)文档说明无匹配返回空值；[公钥](https://docs.volcengine.com/docs/ecs/describekeypairs-querieskeypairlist?lang=en)和[镜像](https://docs.volcengine.com/docs/ecs/DescribeImages-Queriesimages?lang=en)为对象列表，官方 SDK 可表示空列表，但没有用其文档声称实账号必然返回 JSON `null`。空镜像仍按镜像不存在或无权访问停止；公钥及安全组继续执行原有归属、指纹和规则校验。字段缺失、错误类型、空页仍带后续 token 或分页循环继续失败，不推断资源不存在。实例和 EIP 的查询及释放确认仍严格要求数组，不扩大空值兼容。使用 `MaxResults/NextToken` 完成全部分页，终止空页仍保留此前已查到的网段；不使用 token 分页中无意义的 `TotalCount` 判定空集合。[VPC 状态](https://docs.volcengine.com/docs/VirtualPrivateCloud/DescribeVpcs-QueryingaVPClist?lang=zh)中的 `Creating/Pending` 与子网的 `Pending` 均表示尚未就绪，仅 `Available` 才继续，子网还须确认地址可用；已知 ID 即使暂时查不到也保留查询恢复，创建前再次查到同名子网时停止新增。

用户已反馈 VPC 和子网均创建成功，最新失败发生在后续准备阶段。实际顺序为镜像检查、VPC 复核、公钥准备、安全组准备；尚无安全组不能证明已经执行到安全组查询。此前仅修正子网空值处理，其他准备列表的同类限制仍存在，本轮统一处理并补充具体阶段诊断。未取得真实响应正文，不能声称已确认本次唯一根因；更新完整应用后在原记录重试，复用已创建的共享网络。

单次公钥导入或安全组创建/授权后仅查询等待，不自动重发写请求；后续主动重试先按稳定名称查询并使用稳定 `ClientToken`。共享安全组及公钥没有独立的持久化未知意图账本，其跨辅助进程恢复依赖查询及云端 token 幂等，不能把单次不重放测试表述为跨重启绝对不会重复创建。

安全组公网入站固定 SSH 与 Sisters 端口，保留并核验厂商默认的同安全组互通和 IPv4/IPv6 出站规则；其他规则冲突时停止，不自动扩大已有规则。先核对归属和 ID，处于 `Creating` 时只查询等待规则形成；`Available` 必须有完整规则列表，未知状态或就绪后规则列表缺失均停止，不据此补授权。规则与公钥均须核验后复用。私钥只存在本机安全存储和部署进程内存；云端只接收公钥。系统安全存储失败时停止后续购买或删除，不通过普通文件、环境变量或命令行传递秘密。

存在未释放、创建或释放结果未知的实例，或尚未确认的共享网络意图时，不允许移除或替换该厂商凭证。云厂商之间不共用资源账本，不会把腾讯云资源 ID 发送给火山引擎 API。准备及执行 SSH 部署期间禁止释放。

## API 与权限范围

控制端 Go helper 通过固定官方 HTTPS 端点签名调用 `ecs` 和 `vpc`，保留系统证书链与域名验证，拒绝重定向。桌面走标准输入辅助进程，Android 走原生桥接；Sisters 不获得云管理凭证。错误只返回固定脱敏类别，不转发上游消息、请求体或网络错误详情。

VPC 使用 GET 和空请求体，签名包含实际方法、完整查询串、`host` 与 `x-date`；查询按 [官方签名器](https://github.com/volcengine/volc-sdk-golang/blob/main/base/sign.go)的 RFC3986 规则编码，空格为 `%20`，字面加号为 `%2B`。ECS 使用 POST 表单，继续签入 `content-type` 与请求体哈希。查询请求构造不修改调用方参数，不允许业务参数覆盖 Action/Version。

VPC 的创建操作也使用 GET，不能据 HTTP 方法推断可安全重发。该客户端仅启用 HTTP/1.1 并禁用持久连接，每次 API 调用建立独立 TLS 连接：避免 HTTP/1 复用连接错误重试以及 HTTP/2 在 GOAWAY/REFUSED_STREAM 后对空请求体的自动重试。ECS 请求也使用同一传输设置，POST 不提供底层重建请求体回调；所有创建、导入、授权和删除均只发送一次，不做 GET/POST 回退。响应丢失后仍由既有账本查询恢复，不将网络错误当作资源不存在。查询参数、原始请求 URL 与传输错误不进入日志或错误回显。

应用层只为下列 9 个精确 `service + action` 查询组合提供最多 3 次尝试：ECS 的 `DescribeImages`、`DescribeKeyPairs`、`DescribeInstances`、`DescribeAvailableResource`；VPC 的 `DescribeVpcs`、`DescribeSubnets`、`DescribeSecurityGroups`、`DescribeSecurityGroupAttributes`、`DescribeEipAddresses`。仅超时、EOF/UnexpectedEOF 或连接重置/中止等瞬态传输错误触发，包含响应体读取中断；证书校验、永久 DNS/权限错误、云端业务拒绝、超大响应及 JSON 异常不会重试。每轮重新构造请求体和签名，等待分别为 100/200 毫秒，取消立即停止；TLS 握手最多 20 秒、单次请求最多 30 秒，并服从既有整次 helper 操作 3 分钟上限。此策略不以 `GET` 或 `Describe` 前缀推断权限，不改变购买未知状态保护。

需要按实际账号授权以下能力，具体 Action/资源范围依火山 IAM 当前说明，不将列表视作实测的最小权限策略：

- 身份：`GetCallerIdentity`。
- ECS：`DescribeAvailableResource` 库存查询、镜像查询、密钥对查询及导入、`RunInstances`、`DescribeInstances`、`DeleteInstances`。
- VPC：VPC/子网查询与创建、安全组查询与创建、规则查询与添加、EIP 查询。
