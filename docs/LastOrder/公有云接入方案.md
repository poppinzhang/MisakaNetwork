# LastOrder 公有云接入调研与方案

调研日期：2026-11-13。范围：阿里云中国站 ECS、腾讯云 CVM、火山引擎 ECS。

本文整理官方网站的开通步骤、需要交给 LastOrder 的凭据，以及配置模板、创建部署、释放和异常恢复方案。**源码中的腾讯云已实现按量 CVM 安全组、公钥、创建、查询和释放基本流程，详见[腾讯云接入](腾讯云接入.md)；管理员需填写模板后重新打包，操作会产生真实云费用。阿里云与火山引擎仍为预览。** 下方第 0 节保留最初交互预览的实现与验证记录，腾讯云当前行为以专门接入文档为准；第 1～8 节为总体方案，自动部署、完整云资源/费用验收等仍未实现。

本轮核查了官方 API 文档与项目现有部署实现，没有使用真实云账号验证权限，没有购买或释放实例，没有完成实际云镜像、网络、计费或业务验收。云平台界面、购买门槛、库存、权限和 API 参数可能变化，实施时应重新核对本文链接。

## 0. 当前 UI 与交互预览（未发布）

本节记载初始预览阶段。腾讯云现在使用真实 API，固定模板改为打包 JSON，公钥会导入云端；其余两家保持下述预览行为。

### 0.1 凭证入口与本地检查

「公有云部署」导航进入凭证页面，分别展示腾讯云、阿里云、火山引擎，并为其他云厂商保留“等待接入”的空状态。三家表单使用本地账号别名与各自官方命名的两个长期凭据字段，提供对应获取说明；秘密字段默认隐藏。字段依据与核查链接见第 3.1.1 节。

三家厂商标识采用官网提供的品牌小图标，作为 PNG 资源随应用离线打包；厂商选择、凭证表单、手机切换项和云机器卡片共用 `CloudProviderMark`。保持官方原色，浅色/深色界面均在白色圆角底上展示。下载来源、转换方式与校验和维护在 [品牌资源来源](../../LastOrder/assets/cloud_providers/SOURCES.md)，商标归各厂商所有。

录入时检查必填、内部空白/控制字符，以及误填网址或 SSH 密钥等明显格式错误；备注最多 40 字符，每个密钥字段最多 2048 字符，这是本地输入上限，不是云厂商的密钥长度保证。通过后仅表示本地输入符合要求，界面保留“未联网验证”说明，不表示凭据真实有效、拥有创建权限、余额充足或资源可购买。本次没有云端验证请求，也没有 STS 自动续期能力。

云凭据通过独立的 `CloudController` 管理并保存在现有系统安全存储中，不进入普通机器配置、模板、Sisters 配置或日志。安全存储读取、写入失败时显示错误，不将失败伪装成保存成功。当前预览不向云厂商或 Sisters 发送凭据。

### 0.2 添加机器与模板选择

“添加机器”提供“云服务器创建&部署”入口，先选择公有云。已保存且通过本地检查的凭据可进入创建预览；未录入或输入不完整的厂商跳转到其凭证表单。其他厂商仅展示等待接入信息。

每家暂提供三套配置简介，用于比较和选择 UI。它们是示例模板，地域、规格、镜像、网络和价格未与云库存绑定，不能作为可购买配置或报价。后续由作者替换为三到五套经过云端验证的固定模板。

确认一套模板后立即关闭创建弹窗，将独立的云预览记录加入机器管理列表并显示“创建云服务器”；用户可以继续添加其他机器。每条记录独立推进“创建 → 部署 → 完成”的演示状态，也可选择创建失败或部署失败场景查看错误展示。所有状态均明确属于预览，不代表真实资源或 Sisters 已就绪。

云预览记录与现有 SSH 机器、任务记录分开，不参与真实五秒状态轮询，也不能用于分发抢票任务。预览失败保留错误和删除入口；可从预览记录发起释放确认，演示释放进度及完成结果。释放确认和删除失败记录都只改变本地预览，不调用云 API，也不影响原有 SSH 机器。

### 0.3 首次启动的 SSH 登录密钥

LastOrder 首次启动在本地通过 Go 辅助层生成 RSA 2048 位密钥对，私钥保存到系统安全存储；后续启动复用已保存密钥。界面可展示公钥及其指纹，供用户了解本机部署身份。密钥生成或保存失败可重试，不静默覆盖已有密钥。

真实接入时，计划只向云端导入这份公钥，将创建实例绑定到相应云端密钥对，再使用本地私钥完成 SSH 登录和部署；本轮不上传公钥或连接云服务器。登录公钥指纹不能替代服务器主机指纹核验。跨云算法选择依据见第 3.2.1 节，服务器身份引导仍按第 6.2 节实施。

## 1. 方案范围与已有能力

建议采用“云账号 + LastOrder 本地模板 + 云资源记录”的方式。用户一次性准备云账号及网络，保存几套配置，后续选择模板和数量，由 LastOrder 创建服务器并部署 Sisters；需要清理时再释放本次创建的资源。

首期建议范围：

- 接入三家的专用子用户访问密钥，云资源操作在 LastOrder 控制端执行。
- 使用普通按量计费 Linux 实例；镜像以满足当前 Sisters 基线的 Ubuntu 24.04 为起点，分别校验 x64/arm64 的镜像、规格及库存。
- 复用预建 VPC、子网、安全组和 SSH 密钥对，不自动创建、删除共享网络。
- 使用系统盘和必要的公网地址，明确随实例释放属性；暂不自动创建额外数据盘、快照或镜像。
- 复用现有 SSH 离线部署、systemd 用户服务和双向 TLS 通信。
- 提供创建、部署、释放的持久化进度及失败恢复；不把按量实例关机视为已释放资源。

普通云服务器 OpenAPI 使用账号授权和签名凭据，不需要为这一方案另外申请 LastOrder 的 AppID 或 OAuth 应用。云 API 与部署 SSH 是两个独立通道：API 管资源生命周期，SSH 上传应用内的完整离线包，Sisters 的任务控制继续走 gRPC/mTLS。

项目现状与边界见[架构与通信](../架构与通信.md#部署)、[Windows 与 Android](Windows与Android.md)。本方案不改变 [biliTickerBuy 接入安全约束](../biliTickerBuy运行时.md#接入安全约束)：使用项目内嵌运行时，不引入上游 Docker、启动器、Web UI、分享入口或第三方通知，不启用 `local_fanout`，平台 HTTPS 继续校验证书链和域名。

## 2. 三家网站的开通与准备步骤

以下步骤是未来使用云接入功能前的准备，不要求现在购买一台服务器。建议先选定一个地域，验证一套配置，再扩展到更多地域和规格。

文中 VPC 指云上的私有网络，子网（阿里云称交换机）是其中的网段，安全组用于控制服务器允许的网络访问，EIP 指可独立管理和计费的弹性公网 IP。

### 2.1 阿里云 ECS

1. **准备云账号。**注册阿里云账号并完成实名认证，进入 ECS 控制台确认购买资格、按量付费条件、余额及目标地域配额。购买门槛和可用额度以当前账户为准，不把历史文档中的充值数额写成永久要求。[购买指引](https://help.aliyun.com/zh/document_detail/2859053.html)、[按量付费](https://help.aliyun.com/zh/ecs/pay-as-you-go-1)
2. **创建专用 RAM 用户。**在 RAM 访问控制中创建仅用于 LastOrder 的用户，按实际需要启用程序访问，添加云服务器及相关资源的自定义权限。使用专用子用户，不使用主账号 AccessKey；权限范围见第 4 节。[ECS 自定义权限策略](https://help.aliyun.com/zh/ecs/user-guide/custom-policies-for-ecs/)
3. **创建 API 访问密钥。**在该 RAM 用户的凭证管理中创建 AccessKey，保存 `AccessKey ID` 与 `AccessKey Secret`。Secret 仅创建时提供，应当时保存；这不是 RAM 用户的网页登录密码。[创建 AccessKey](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)
4. **准备网络。**在目标地域创建或选用专用 VPC、交换机 VSwitch、安全组。交换机对应的可用区必须与机型可用区匹配。安全组规则见第 5 节。
5. **准备 SSH 公钥。**在云端导入专用 SSH 公钥并记录密钥对名称，本地保管对应私钥。LastOrder 源码已支持在本地生成专用密钥；自动导入公钥仍需要后续云 API 实现和授权。
6. **在 LastOrder 录入账号、选择资源并保存模板。**云端对象应由查询接口列出供用户选择，不要求手工抄录所有 ID。对应的创建参数见 [RunInstances](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runinstances)。

### 2.2 腾讯云 CVM

1. **准备云账号。**注册腾讯云账号并实名认证，确认 CVM 按量购买条件、余额和目标地域配额。当前官方说明创建按量 CVM 时会冻结一小时主机费用，应以实际配置和账户显示为准。[使用限制](https://cloud.tencent.com/document/product/213/15379)
2. **创建专用 CAM 子用户。**在访问管理中创建专用子用户，按实际需要启用编程访问并附加自定义权限。子用户获得的权限应仅覆盖本方案使用的资源和操作。[用户类型](https://cloud.tencent.com/document/product/598/13665)、[CVM 可授权资源](https://cloud.tencent.com/document/product/213/10314)
3. **创建 API 密钥。**为该子用户创建并保存 `SecretId` 和 `SecretKey`；SecretKey 应在创建时妥善保存。CVM API 接入不使用 AppID、网页登录密码或 SSH 私钥作为云 API 凭据。[子账号密钥管理](https://intl.cloud.tencent.com/zh/document/product/598/32675)
4. **准备网络。**在目标地域准备 VPC、子网及专用安全组，确认子网所属可用区和所选机型一致。
5. **准备 SSH 公钥。**在云端导入公钥，记录 `KeyId`，本地保留对应私钥。登录用户由镜像和初始化方案决定，不统一假设为 `root`。
6. **在 LastOrder 保存模板。**选择按量 CVM、镜像、实例规格、系统盘、公网配置和前述网络资源。对应参数见 [RunInstances](https://cloud.tencent.com/document/api/213/15730)。

### 2.3 火山引擎 ECS

1. **准备云账号。**注册火山引擎账号并实名认证，确认 ECS 按量购买资格、余额、实例及 EIP 配额。调研时按量购买文档要求现金余额与代金券合计不低于 100 元；实际开户、支付和后续使用条件以当前账户为准。[购买与使用](https://docs.volcengine.com/docs/ecs/Buying-and-using-ECS-instances?lang=zh)、[按量计费](https://docs.volcengine.com/docs/ecs/pay-as-you-go?lang=zh)
2. **创建专用 IAM 用户。**在访问控制中创建 LastOrder 专用用户并授权，按需要选择项目及资源范围。查询与写入接口支持的项目授权范围不同，不能给所有操作套用同一个项目条件。[ECS API 与授权范围](https://docs.volcengine.com/docs/ecs/elastic-compute-service-api-overview?lang=zh)
3. **创建 Access Key。**在该用户的密钥页面创建并保存 `Access Key ID`、`Secret Access Key`。这里需要标准云 OpenAPI 的签名密钥，不能使用火山方舟、豆包等产品的模型 API Key 替代。[API 密钥管理](https://docs.volcengine.com/docs/iam/api-access-key-management?lang=zh)
4. **准备网络。**在目标地域准备 VPC、子网、安全组，确认公网 EIP 规格、配额与计费方式。首期采用普通可用线路；特殊线路、邀测规格或超额资源可能另需申请。
5. **准备 SSH 公钥。**导入公钥，记录 `KeyPairName`，本地保存私钥及登录用户配置。
6. **在 LastOrder 保存模板。**除实例、系统盘、子网与安全组外，明确 EIP 的计费、带宽和随实例释放属性。创建公网实例涉及 EIP 权限，不能只授予 ECS 操作权限。[RunInstances](https://docs.volcengine.com/docs/ecs/runinstances-createsinstances?lang=zh)

## 3. 需要提供给 LastOrder 的内容

### 3.1 云账号与凭据

| 云厂商 | 必需的长期 API 凭据 | 另行选择或查询的信息 |
| --- | --- | --- |
| 阿里云 | 专用 RAM 用户的 `AccessKey ID`、`AccessKey Secret` | 账号别名、地域、可选资源组 |
| 腾讯云 | 专用 CAM 子用户的 `SecretId`、`SecretKey` | 账号别名、地域、可选项目 |
| 火山引擎 | 专用 IAM 用户的 `Access Key ID`、`Secret Access Key` | 账号别名、地域、可选项目 |

云账号 ID、项目或资源组用于归属校验和权限约束，不替代签名密钥。连接验证应尽可能查询实际账号身份并绑定，防止更换密钥后把原资源记录错误关联到另一个账号。

长期密钥只保存在 LastOrder 所在设备的系统安全存储中；普通元数据只存凭据引用和必要展示信息。不得将云密钥写入模板导出、日志、命令行、初始化脚本或 Sisters 配置，也不下发到 Sisters。密钥失效时暂停云操作并提示更新，不能因此删除云资源记录或声称资源已经释放。

三家均支持临时凭据，作为后续可选模式：

| 云厂商 | 临时凭据组成 |
| --- | --- |
| 阿里云 STS | 临时 `AccessKeyId`、`AccessKeySecret`、`SecurityToken`、到期时间 |
| 腾讯云 STS | `TmpSecretId`、`TmpSecretKey`、`Token`、到期时间 |
| 火山引擎 STS | 临时 `AccessKeyId`、`SecretAccessKey`、`SessionToken`、到期时间；SDK 按其安全令牌字段配置，字段见[官方 AssumeRole 示例](https://docs.volcengine.com/docs/observability/Embedding_custom_dashboards?lang=en) |

手工导入一次 STS 凭据不会自动续期。长期无人干预管理还需要明确的角色授权、身份联邦或可信凭据服务；仅让本地应用持有另一把长期密钥去换取 STS，并没有消除本地长期密钥。首期不依赖自建凭据服务。[阿里云凭据管理](https://help.aliyun.com/zh/sdk/developer-reference/v2-manage-go-access-credentials)、[腾讯云 STS 数据结构](https://cloud.tencent.com/document/api/1312/48198)、[火山引擎临时凭证实践](https://docs.volcengine.com/docs/iam/temporary-certificate-best-practices?lang=zh)

### 3.1.1 本轮凭证表单核查

2026-11-13 再次核对三家官方资料。虽然首期都使用一对长期访问密钥，表单应保留各家的原始字段名称、所属用户类型和获取指引，不能展示成统一的“用户名 / 密码”表单。

| 云厂商 | 表单字段 | 用户准备方式与区别 |
| --- | --- | --- |
| 腾讯云 | `SecretId`、`SecretKey` | CAM 子用户的 API 密钥；不是 AppID、UIN 或控制台密码。SecretKey 只在创建时提供。[子账号访问密钥管理](https://intl.cloud.tencent.com/zh/document/product/598/32675) |
| 阿里云 | `AccessKey ID`、`AccessKey Secret` | RAM 用户的 AccessKey；不是阿里云账号密码。Secret 只在创建时显示。[创建 AccessKey](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair) |
| 火山引擎 | `Access Key ID`、`Secret Access Key` | IAM 用户的标准云 OpenAPI 签名凭据；不是部分 AI 产品使用的 Bearer API Key。[凭证类型](https://docs.volcengine.com/docs/iam/api-access-key-management?lang=zh)、[官方 SDK 凭证说明](https://github.com/volcengine/volc-sdk-golang/blob/main/README.md) |

首期仅提供长期凭据表单，不混入 STS Token、网页登录密码或 SSH 私钥字段。账号别名属于本地展示信息；地域、项目/资源组以及 VPC 等属于未来模板和资源选择信息，不是新增的身份凭据。

UI 阶段只做本地输入检查，不能据此声称密钥已被云端认可。界面需要区分“尚未填写”“格式检查通过”“未联网验证”，完成输入后可继续预览创建交互；真正的有效性、账号归属、权限、配额和可购买性仍待后续云 API 验证。不要仅凭示例推导固定长度或唯一前缀：腾讯国际站文档当前列出 `IKID`，也不能因此拒绝其他受支持站点的既有凭据。

### 3.2 SSH 登录身份

API 密钥用于管理云资源，SSH 密钥用于登录操作系统，两者不能互换。每套模板需要：

- 云端 SSH 密钥对名称或 ID，以及对应的本地私钥安全引用。
- 镜像默认用户或初始化脚本创建的专用部署用户；必要时在内存中使用私钥口令。
- SSH 端口及 Sisters gRPC 端口。

未来可提供“导入已有私钥”和“本地生成专用密钥对并上传公钥”两种方式。私钥始终保留在本地受保护存储中，不放进云 UserData。云平台密钥对页面显示的公钥指纹属于**登录密钥**，不能拿来验证新服务器的 **SSH 主机密钥**；后者的可信获取见第 6.2 节。

### 3.2.1 本地生成密钥的跨云兼容依据

本轮核查优先选择 RSA 2048 位，并使用 OpenSSH 公钥格式作为三家接入的共同起点。腾讯云当前 `ImportKeyPair` 明确要求 OpenSSH RSA；阿里云支持 `ssh-rsa`；火山引擎说明创建密钥对采用 RSA 2048 位，导入接口示例使用 `ssh-rsa`。这些资料不构成 Ed25519 在三家云端密钥服务均可导入的依据，也不代表所有 RSA 长度都已验证。[腾讯云导入公钥](https://cloud.tencent.com/document/api/213/15703)、[阿里云导入公钥](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-importkeypair)、[火山引擎密钥限制](https://docs.volcengine.com/docs/ecs/key-pair-overview?lang=zh)、[火山引擎导入公钥](https://docs.volcengine.com/docs/ecs/importkeypair-importskeypairs?lang=zh)

公钥文件中的 `ssh-rsa` 类型不要求 SSH 握手降级使用 SHA-1 签名；接入时仍应使用现有 SSH 库与服务器协商受支持的现代签名算法。[OpenSSH 对 RSA 密钥与签名算法的说明](https://www.openssh.org/txt/release-8.8) 云端导入公钥、绑定实例和后续 SSH 部署是三个独立步骤。UI 预览不会上传公钥或创建实例；真实接入还需逐家验证导入、绑定、登录、主机身份校验及私钥安全存储。

## 4. 权限边界

以下是权限设计范围，不是已经通过实账号测试的最小权限策略。实施时需要分别编写 RAM、CAM、IAM 策略，并核对每个 Action 的关联权限、资源范围及条件支持。

| 能力 | 建议权限范围 |
| --- | --- |
| 模板选择与预检 | 查询地域、可用区、规格、镜像、VPC、子网、安全组、SSH 密钥对；按需加入询价和配额查询 |
| 实例生命周期 | 创建、查询、设置必要的归属标签、停止或释放本项目创建的实例 |
| 公网和磁盘 | 仅为实际使用的 EIP、磁盘增加创建、关联、查询、解绑和释放权限；共享资源不授予删除权限 |
| SSH 信任引导 | 云助手状态查询、执行固定的主机公钥读取操作、查询执行结果 |
| 可选功能 | 自动导入公钥、云端启动模板、定时释放等应单独说明新增权限 |

优先按地域、项目、资源组或已知资源 ID 收窄可限制的操作；并非所有查询或创建 Action 都支持相同限制。标签用于辅助识别归属，不应被当成独立、充分的授权或删除依据。初期预建网络能避免授予 VPC、子网和共享安全组的创建、删除权限。

`RunCommand` 即使仅执行读取公钥的脚本，权限本身仍可能允许远程执行其他命令，不能称为只读权限。更窄的替代是预建固定命令并授权调用，逐家核对是否能限定命令和实例；例如火山引擎可对 `InvokeCommand` 的命令资源授权，但同时授予修改命令能力会破坏这一限制。若用户不接受云助手权限，应保留人工核验入口。[腾讯云 TAT 访问管理](https://cloud.tencent.com/document/product/1340/56294)、[火山引擎自定义命令权限](https://docs.volcengine.com/docs/ecs/configuring-permissions-for-using-custom-commands?lang=en)

## 5. 固定配置模板

### 5.1 本地模板为主

建议 LastOrder 统一保存模板，每个云账号可有多套。比如同一云的“地域 A / x64 / 小规格”和“地域 B / arm64 / 中规格”是两套独立配置；机型、镜像与网络 ID 按云厂商和地域分别选择，不进行跨云字符串替换。

| 配置组 | 保存内容与约束 |
| --- | --- |
| 身份与位置 | 云厂商、云账号引用、地域、可用区、可选项目或资源组 |
| 系统与计算 | 明确的镜像 ID、x64/arm64、实例规格；验证镜像与实例架构一致 |
| 系统盘 | 类型、容量、释放策略；首期不自动添加数据盘、快照 |
| 网络 | VPC、交换机/子网、安全组、公网 IP/EIP 方式、带宽或流量计费设置 |
| SSH | 密钥对标识、本地私钥引用、登录用户、SSH 端口 |
| Sisters | gRPC 端口、并发配置、与当前完整 LastOrder 所携离线包一致的版本与目标架构 |
| 费用与数量 | 普通按量计费、默认数量、数量上限、费用提示；不自动升级为更贵规格或切换计费模式 |
| 管理信息 | 模板名称、修订号、资源归属标签、上次参数检查结果 |

模板不保存 Cookie、购票人信息、云密钥或 SSH 私钥内容。模板修订不改变已经创建的实例；每次创建保留当时的配置快照，以便查询与释放。

镜像 ID 固定后也可能下架，实例库存和价格会变化，保存成功不等于下次一定能够购买。每次创建前重新检查；缺货时允许用户选另一套已确认模板，不静默更换地域、架构或规格。

### 5.2 网络与初始化要求

首期建议每台机器具备控制端可达的公网地址。安全组和主机防火墙需允许控制端访问 SSH（默认 TCP `22`）及实际配置的 gRPC 端口（新机器默认 TCP `20001`），并满足系统、云助手和运行时的必要出站访问。

来源地址建议限制在用户实际使用的控制端出口范围。Android 切换 Wi-Fi/移动网络后可能改变公网出口，需要明确的更新规则或后续私网接入方案，不以静默放开所有来源来掩盖连通性错误。

初始化使用固定、可审阅的 cloud-init/UserData 模板，处理专用普通用户、SSH 公钥、必要的系统运行条件和 `loginctl enable-linger <部署用户>`。开启 linger 由初始化阶段的管理员权限完成；既有 SSH 部署器仍按现有规则检查，不增加隐式提权行为。应检查初始化成功而不是仅等一个固定时长。

UserData 不是秘密存储；Base64 是编码，不是加密。云密钥、Cookie、购票配置、SSH 私钥和 mTLS 私钥不得写入其中。项目的 Sisters、Python 和 biliTickerBuy 仍由本地完整离线包上传，不在开机脚本中下载上游应用。[阿里云用户数据注意事项](https://www.alibabacloud.com/help/en/auto-scaling/use-cases/enable-the-instance-user-data-feature-to-automatically-configure-ecs-instances)

### 5.3 云端启动模板作为可选入口

三家都提供启动模板。后续可支持导入或引用，但应固定“云账号 + 地域 + 模板 ID + 明确版本”，避免默认版本变化后产生不同配置。密码、私钥和本地部署参数仍需独立管理；云端模板不是 LastOrder 完整模板的替代，也不保证库存或部署成功。[阿里云创建参数](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runinstances)、[腾讯云启动模板](https://cloud.tencent.com/document/product/213/62034)、[火山引擎启动模板](https://docs.volcengine.com/docs/ecs/creating-launch-templates?lang=zh)

## 6. 创建与自动部署流程

### 6.1 云 API 与实例就绪

| 云厂商 | 创建与查询 | 关键设置 |
| --- | --- | --- |
| 阿里云 | `RunInstances` → `DescribeInstances` / `DescribeInstanceStatus` | `PostPaid`、`NoSpot`；公网带宽配置决定普通公网 IP 分配；使用 `ClientToken` |
| 腾讯云 | `RunInstances` → `DescribeInstances` / `DescribeInstancesStatus` | `POSTPAID_BY_HOUR`；显式配置公网访问、SSH 密钥和云助手；使用 `ClientToken` |
| 火山引擎 | `RunInstances` → `DescribeInstances` | `PostPaid`；明确 EIP 计费与释放属性；使用 `ClientToken` |

官方接口：[阿里云创建](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runinstances)、[阿里云查询](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeinstances)、[腾讯云创建](https://cloud.tencent.com/document/api/213/15730)、[腾讯云查询](https://cloud.tencent.com/document/api/213/15728)、[火山引擎创建](https://docs.volcengine.com/docs/ecs/runinstances-createsinstances?lang=zh)。

建议按以下顺序执行，每一步有独立状态和超时：

1. **选择并预检。**选择账号、模板与数量，检查凭据、权限、镜像、规格、网络、配额及可用的询价结果，展示本次资源和预计费用。可用时调用 DryRun；预检成功不保证实际创建时仍有库存，估价不等于最终账单。
2. **先记录意图，再发送请求。**持久化创建操作 ID、模板快照、数量和稳定的 `ClientToken`。同一请求超时重试使用相同 token 和参数，不因未收到响应就生成新 token 再次购买。
3. **登记返回资源。**保存实际实例 ID、地域及云端请求 ID，逐台记录创建进度。批量创建可能部分成功，不能把整个批次笼统标为成功或失败。
4. **等待就绪。**轮询实例状态并取得实际公网地址，处理创建失败及超时。实例处于运行状态后，继续检查初始化、云助手或 SSH 可用性；返回实例 ID 不表示可部署。
5. **验证 SSH 主机身份。**采用第 6.2 节的可信引导方案，或由用户人工核对。
6. **执行现有部署。**按系统和架构选择当前 LastOrder 携带的同版本完整离线包，上传、自检、配置节点证书、启动 systemd 用户服务。继续沿用现有超时、切换和回滚规则。
7. **确认可用。**分别记录安装结果与控制端到实际 gRPC 地址的 mTLS 检查结果。现有部署在直连失败时可能已安装成功；云流程应显示“已部署但不可达”，不误报部署回滚，也不标记为可分发。
8. **接入任务管理。**成功且可达的节点进入普通机器列表，之后使用现有任务创建、分发与监控流程。创建机器本身不自动分发抢票任务。

### 6.2 首次 SSH 主机身份验证

现有 LastOrder 首次连接需要用户核对 SHA-256 主机指纹。完全自动部署不能通过关闭验证、接受首次见到的公钥，或直接信任 `ssh-keyscan` 结果来实现。

三家云助手提供了另一条可认证的通道：

| 云厂商 | 执行与读取结果接口 | 前置条件 |
| --- | --- | --- |
| 阿里云云助手 | `RunCommand`、`DescribeInvocationResults` | 实例运行，客户端安装且在线；不能仅凭公共镜像默认预装就跳过状态检查 |
| 腾讯云 TAT | `RunCommand`、`DescribeInvocationTasks` | 支持的地域/VPC，客户端在线；创建参数可显式启用自动化助手 |
| 火山引擎云助手 | `RunCommand`、`DescribeInvocationResults` | 实例运行，客户端安装并注册；创建时显式设置 `InstallRunCommandAgent=true`（默认 `false`），或验证镜像已有客户端 |

依据：[阿里云执行命令](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runcommand)、[读取结果](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeinvocationresults)、[客户端条件](https://help.aliyun.com/zh/ecs/user-guide/install-the-cloud-assistant-agent)；[腾讯云执行命令](https://cloud.tencent.com/document/product/1340/52676)、[读取结果](https://cloud.tencent.com/document/product/1340/52680)、[使用条件](https://cloud.tencent.com/document/product/1340/50821)；[火山引擎执行命令](https://docs.volcengine.com/docs/ecs/runcommand-execute-command?lang=en)、[读取结果](https://docs.volcengine.com/docs/ecs/DescribeInvocationResults_-_View_command_execution_results?lang=en)、[客户端条件](https://docs.volcengine.com/docs/ecs/overview-of-cloud-assistant?lang=zh)。

基于这些接口，建议通过已认证、校验服务器证书的 HTTPS 云 API，在本次创建的精确实例上执行固定命令，读取 `/etc/ssh/ssh_host_*_key.pub` 中拟用于 SSH 握手的公钥。校验执行 ID、实例 ID、成功状态、退出码和输出格式，再将公钥与账号、地域、实例 ID 绑定并用于 SSH 校验。

**这是根据接口能力提出的设计，尚未完成真机验证，也不是云实例查询直接返回主机公钥的现成功能。**云助手缺失、权限不足、输出异常或身份不符时，停在身份验证阶段并保留人工核对入口。重装系统可能更换主机公钥，需要重新进行可信核验，不能自动接受变化。

### 6.3 部署失败与恢复

机器创建成功后，SSH 不通、初始化失败或包部署失败都不等于资源已释放。界面应持续展示资源 ID、状态和计费可能性，提供“重新检查”“重新部署”“释放资源”。默认保留可管理记录；若后续提供失败自动清理，应在创建前明确策略，并只清理该次操作确实创建的资源。

应用重启后应从本地操作记录恢复云资源查询，而不是自动重新创建机器或重新提交抢票任务。若创建响应丢失，应结合相同 token、云端查询和归属信息进行对账；超过云端幂等保证范围且无法确认结果时，标记“创建结果待核实”，不盲目重新购买。

## 7. 释放与资源核对

### 7.1 各云释放差异

| 云厂商 | 实例释放 API | 必须另外核对的事项 |
| --- | --- | --- |
| 阿里云 | `DeleteInstances` | EIP 不随实例释放；云盘取决于 `DeleteWithInstance`，自动快照取决于相应属性，手动快照保留并计费。运行中释放的 `Force` / `ForceStop` 需明确设置 |
| 腾讯云 | `TerminateInstances` | 按量实例直接销毁；`ReleaseAddress` 默认 `false`，且覆盖的 EIP 类型及网卡范围有限，不能视为释放所有 EIP；磁盘按各自生命周期处理 |
| 火山引擎 | `DeleteInstance` / `DeleteInstances` | 创建时 `EipAddress.ReleaseWithInstance` 默认 `false`，仅按量 EIP 支持随实例释放；检查云盘属性；批量结果逐项核对 `OperationDetails` |

依据：[阿里云释放规则](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-deleteinstances)、[腾讯云释放规则](https://cloud.tencent.com/document/api/213/15723)、[火山引擎创建属性](https://docs.volcengine.com/docs/ecs/runinstances-createsinstances?lang=zh)、[火山引擎批量删除](https://docs.volcengine.com/docs/ecs/deleteinstances-deletesinstances?lang=en)。

首期对专为本次实例创建的按量系统盘/EIP 显式设定释放策略，仍记录并查询最终状态。共享 VPC、子网、安全组、SSH 公钥和启动模板不在单台机器的释放范围内。外部导入或用户原有的磁盘、EIP 不能因为当前关联到实例就被认定为本项目可删除资源。

例如，火山引擎为本次实例新建专用按量 EIP 时，应显式设置 `EipAddress.ReleaseWithInstance=true`，并在释放后再次查询核实；不能依赖默认值。

### 7.2 建议释放流程

1. **选择实例并展示影响。**列出云账号、地域、实例 ID、将删除的附属资源及当前已知任务；状态查询失败时明确标注任务状态未知。释放会结束实例上的任务，需要用户在核对范围后发起操作。
2. **停止新分发。**将所选机器标记为待释放，阻止继续提交任务。尝试取消未结束任务并等待结果；机器失联时不能假称任务已停止，是否继续强制释放由用户明确选择。
3. **提交云端释放。**持久化操作状态，调用对应接口。处理释放保护、运行状态限制、权限不足和批量部分失败；HTTP 成功或返回请求 ID 不代表所有实例已释放。
4. **等待并核查。**查询实例最终状态，核对本次拥有的系统盘、EIP 及已知其他附属资源。对于需独立解绑/释放的资源按依赖顺序处理；查询失败不视为资源不存在。
5. **记录最终结果。**只有实例和应清理的附属资源均确认释放后，才标记“释放完成”。若仍有 EIP 或磁盘，显示“实例已释放，附属资源待清理”，保留具体 ID 和重试入口。
6. **保留必要管理记录。**保留不含秘密的操作结果、资源归属与云请求 ID，停止节点轮询。清理节点专属本地引用时核对是否共享，不删除控制端 CA、账号凭据或其他机器仍使用的密钥。

“从本地机器列表移除”和“释放云服务器”应是含义明确的不同操作。现有删除机器记录不会取消远程任务，这一语义不能在增加云功能后悄悄改变。存在未释放资源时，不应允许只删账号凭据或管理记录却不告知用户仍有资源需要处理。

### 7.3 应用退出与费用边界

关闭 LastOrder、Android 进入后台、删除本地记录或仅关闭操作系统，都不能被描述为已经停止所有云费用。资源释放依赖云端实际结果，独立 EIP、保留磁盘与快照应单独核对。

后续可提供用户明确选择的云端截止时间，作为控制端离线时的补充：阿里云 `AutoReleaseTime`、腾讯云 `ActionTimer` 有相关能力，但需要核验配置、附属资源释放范围和实际行为；火山引擎的对应方案本轮未完成确认。不能统一承诺三家都具备同一自动释放能力，也不能用本地定时器保证应用关闭后的释放。到期销毁会中断尚未结束的任务。[阿里云创建参数](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runinstances)、[腾讯云定时操作结构](https://cloud.tencent.com/document/product/213/15753)

## 8. 实现方向与后续验证

### 8.1 建议职责划分

- Flutter 管理账号、模板、资源列表、费用提示和进度。
- 现有 Go 辅助层增加按厂商划分的云适配器，使用官方 SDK 处理签名与 API 错误；桌面端走辅助进程，Android 复用 JNI 通道并单独验证 SDK 构建和运行。
- 使用 HTTPS 并保留云 API 的证书链及域名验证；Sisters 不持有管理云资源的权限。
- 云操作记录与现有任务记录分开。前者至少包括账号归属、地域、模板快照、操作 ID、幂等 token、云资源 ID、资源所有权、操作状态及脱敏错误。
- 重启恢复的是云操作查询与管理，不是自动恢复 Sisters 的任务或重新执行购票请求。

三家的官方 Go SDK 入口：[阿里云](https://help.aliyun.com/zh/ecs/developer-reference/ecs-sdk-reference/)、[腾讯云](https://cloud.tencent.com/document/sdk/go)、[火山引擎](https://docs.volcengine.com/docs/ecs/Elastic-Compute-Service-SDK-overview?lang=en)。SDK 依赖及锁定文件尚未修改，Android 适配尚未验证。

### 8.2 实施前与交付前需要验证的项目

| 范围 | 验证内容 |
| --- | --- |
| 授权 | 三家专用用户完整创建/查询/部署/释放；越权访问、缺少关联权限和已撤销密钥正确失败 |
| 凭据 | 三平台安全存储、错误脱敏、私钥与云密钥不进入普通文件、导出和云端 UserData |
| 模板 | 镜像下架、架构不匹配、地域/可用区不一致、规格缺货及配置修订 |
| 创建 | 幂等重试、响应丢失、限流、余额/配额不足、部分成功和应用重启对账 |
| 主机信任 | 云助手离线、错误实例/执行 ID、异常输出、主机密钥变化及人工核验路径 |
| 部署 | 实际镜像的系统依赖、linger、离线包、SSH 超时、服务启动、回滚和公网 mTLS 检查 |
| 清理 | 停止任务、失联机器、释放保护、独立 EIP、保留磁盘、部分失败及幂等重试；核对最终资源和账单 |
| 客户端 | Windows/macOS/Android 的创建与释放操作中断、重启恢复和 Android 后台限制 |

先用离线模拟覆盖错误与状态转换，再对每个云、每种承诺支持的镜像/架构组合进行受控真机验证。记录源码测试、云接口验证、完整离线包部署、资源与费用核对的各自范围；它们均不代表真实账号登录、下单或出票已验收。
