# 关于页面的开源许可

「关于 LastOrder」底部的「开源许可与第三方声明」进入离线许可列表，选择组件即可查看许可原文与版权声明。页面使用 `material_ui` 的 `LicensePage`，不需要联网；返回后保留关于窗口。

## 许可来源

- Flutter 构建工具自动收集 Flutter、Dart 包及其携带的第三方通知，通过 `LicenseRegistry` 提供；新增的 `url_launcher` 及各平台实现也由此收集。
- `LastOrder/assets/licenses/third_party_licenses.json` 补充 Flutter 不会自动收集的组件，包括 biliTickerBuy、Go 与当前 Go 模块、Python、锁定的桌面与 Android Python 依赖，以及 Chaquopy。biliTickerBuy 条目保留 `runtime/NOTICE.txt`、Required Notice 与完整的 PolyForm Noncommercial License 1.0.0 原文，因此入口同时使用「第三方声明」名称。
- 补充资产由 `scripts/collect_licenses.py` 从现有原生运行时 `licenses/`、Windows 完整包、Android APK 内的 Python 依赖许可、Go 模块缓存和固定版本的补充许可文本生成，不执行上游应用代码、不登录或下单。补充原文保存在 `scripts/license_sources/`，来源 URL 记录在 `scripts/third_party_licenses_manifest.json`。
- 清单保存依赖输入与资产的 SHA-256；离线校验覆盖锁定的 Python 依赖和 `go.mod` 中的模块，依赖、上游许可或资产变化后需同步更新。许可文本中的作者姓名与版权归属是上游声明，不是本机开发环境信息。

补充资产当前包含 50 个组件条目，复用 Linux/macOS 四种运行时及 Windows、Android 包中的许可文本。这是已采集源码与许可材料的展示范围，不等同于所有原生传递依赖或最终发行二进制已完成合规审计；发布时仍须核对实际交付的组件、版本与应附带的声明，并保留运行时包中的原许可文件。

## 更新与验证

依赖不变时，应用与测试直接使用已提交的资产，不要求本机具备全部平台构建环境：

```sh
python3 scripts/collect_licenses.py --check
python3 -m unittest discover -s scripts -p 'test_collect_licenses.py' -v
cd LastOrder
flutter test test/about_test.dart test/open_source_licenses_test.dart
```

更新依赖后，在具备对应版本构建材料的环境重新采集。以下路径仅为通用示例；重复传入 `--runtime-licenses` 可合并不同平台/架构随包附带的许可：

```sh
python3 scripts/collect_licenses.py \
  --runtime-licenses /tmp/license-inputs/linux-amd64/licenses \
  --runtime-licenses /tmp/license-inputs/linux-arm64/licenses \
  --runtime-licenses /tmp/license-inputs/macos-amd64/licenses \
  --runtime-licenses /tmp/license-inputs/macos-arm64/licenses \
  --runtime-archive /tmp/license-inputs/LastOrder-windows.zip \
  --android-apk /tmp/license-inputs/LastOrder-android.apk
```

准备材料时须核对其依赖与仓库锁定版本一致；解释器或原生库升级也要重新收集，即使 Python 包锁定文件没有改变。Go 模块缓存须预先就绪，采集脚本关闭 Go 在线下载。若依赖未携带许可文件，从对应固定版本官方来源补充原文并记录来源，不能用 SPDX 名称或在线链接替代完整文本。

`open_source_licenses.dart` 先读取并完整校验补充资产，再幂等追加到 Flutter 许可注册表；解析失败不注册部分数据。读取失败页面保留返回与重试入口，重试绕过失败的资产缓存。关于页的两处外链使用系统浏览器，调用方式见 [`url_launcher` 官方说明](https://pub.dev/packages/url_launcher)；平台返回失败或异常时展示可复制的网址。
