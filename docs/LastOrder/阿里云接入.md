# LastOrder 阿里云接入（未发布）

本次接入使用阿里云中国站的普通按量 ECS，沿用腾讯云的模板选择、后台创建、主动部署和释放交互。实现位于当前源码，尚未发布安装包；不以源码或模拟测试代替真实账号、资源、默认镜像登录、计费或业务验收。管理员填写模板后需要重新构建完整应用。

## 使用流程与资源范围

1. 在「公有云部署」选择阿里云，录入 RAM 用户的 AccessKey ID 与 AccessKey Secret。调用官方 STS `GetCallerIdentity` 验证成功后保存，每厂商只保留一份凭证。身份查询成功不保证创建权限、余额、配额或库存。
2. 在「添加机器 → 云服务器创建」选择阿里云与打包模板。初始模板为空，没有模板时不能购买。确认后先保存资源记录，再在后台准备网络、镜像、公钥和安全组。
3. 创建成功并取得公网地址后，在原云卡片点击「部署 Sisters」。应用使用安全存储中的原 SSH 私钥、首次自动保存服务器指纹及既有离线部署流程，不导出私钥文件。阿里云使用模板明确填写的 `sshUsername` 密钥登录；不套用腾讯云的限定 sudo 选项。
4. 部署成功后才能分发任务。准备与部署期间禁止释放；部署失败在原卡片重试。重启应用只恢复云状态查询，不自动继续 SSH 部署。
5. 停止使用时主动释放。释放会结束服务器上的任务；关闭应用或移除本地连接不会停止云端计费。释放请求受理不等于释放完成，只有查询确认后才移除活动卡片与分发候选，历史任务关联保留。

本次仅创建一台普通按量实例、一个系统盘与直接分配的公网 IPv4，不创建独立 EIP、数据盘、快照、启动模板、抢占式实例或用户脚本。`RunInstances` 固定 `Amount=1`、`InstanceChargeType=PostPaid`、`SpotStrategy=NoSpot`，公网固定按流量计费；`InternetMaxBandwidthOut>0` 由 ECS 自动分配公网 IP。模板不允许覆盖生命周期策略。[RunInstances 官方说明](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-runinstances)

## 模板与仓库外配置网页

应用资产为 `LastOrder/assets/cloud_templates/aliyun.json`：

```json
{"schemaVersion":2,"templates":[]}
```

每个条目包含 `id`、`name`、`description`、`cpu`、`memoryGb`、`diskGb`、`architecture`、`os`、`sshUsername`、`regionLabel`、`region` 和 `runInstances`。全部必填且拒绝额外字段；架构为 `x64` 或 `arm64`，`os` 为非空系统显示名，`sshUsername` 为镜像实际允许密钥登录的账号。

| `runInstances` 字段 | 约束 |
| --- | --- |
| `ZoneId` | 同地域建议可用区，例如 `cn-hangzhou-h` 或 `ap-southeast-1a`；数字结尾地域后直接追加区字母，其他地域追加 `-` 与区字母 |
| `InstanceType` | 阿里云 `ecs.` 开头的机型标识 |
| `ImageId` | 阿里云镜像 ID，不限 Linux 发行版、版本或来源，创建前核对 Linux 类型、架构、可用状态、容量及磁盘条件；官方公共镜像允许未返回映射，非空映射须为唯一系统盘，拒绝附带数据盘 |
| `SystemDisk.Category` | `cloud_efficiency`、`cloud_ssd`、`cloud_essd`、`cloud_essd_entry` 或 `cloud_auto` |
| `SystemDisk.Size` | 20–2048 GiB 的整数，等于 `diskGb` |
| `InternetChargeType` | 固定 `PayByTraffic` |
| `InternetMaxBandwidthOut` | 1–100 Mbps 的整数 |

管理员工具放在仓库外，支持模板编辑、校验、导入导出及官方只读选项查询，不打包到应用。模板不接受密钥、端点、VPC/交换机 ID、密码、UserData、数据盘或任意 API 参数；真实环境资料不要提交公共仓库。展示规格由管理员核对，格式通过不等于实时库存或报价保证。修改模板后需重新打包，不热更新已创建实例。

### 公共镜像磁盘映射检查（2026-11-14）

`DescribeImages` 的官方公共镜像可能返回唯一磁盘映射但不填写 `Type`；阿里云[历史 API 文档的公共 Ubuntu 示例](https://docs-aliyun.cn-hangzhou.oss.aliyun-inc.com/pdf/ecs-open-api-intl-en-2016-09-14.pdf#page=137)即为此形状。[当前接口说明](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeimages)将映射定义为磁盘与快照的关系，顶层 `Size` 仅代表系统盘容量，不能据此认定不存在数据盘。

用户随后重试的截图明确进入“缺少磁盘映射信息”分支，原先只允许唯一映射缺省类型的修复未覆盖该情况；截图尚不能区分字段缺省、`null` 或空列表。准备与购买前现均先核对精确镜像 ID、Linux 类型、架构、`Available` 状态及正整数系统盘容量，要求容量不超过模板。仅当云端返回 `ImageOwnerAlias=system` 时，允许映射容器或列表缺省、为 `null` 或为空，采用已验证的顶层系统盘容量；不会根据镜像名称、模板系统显示名或 `IsPublic=true` 将其它来源当作官方公共镜像。来源分类与容量字段含义见[官方 DescribeImages 说明](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeimages)。

若返回非空映射，仍要求恰好一条；显式 `system` 类型正常校验，仅官方公共来源允许该唯一映射的类型缺省或为空。映射容量须为正整数、等于顶层 `Size` 且不超过模板系统盘。自定义、共享、社区、市场及未知来源仍必须明确返回单系统盘映射；错误容器/列表类型、空元素、数据盘、多盘、未知类型和容量异常继续阻止后续写操作。创建请求仍只指定系统盘，不添加数据盘参数；释放前的实际云盘检查不变。

不符合上述条件的缺失映射提示“模板镜像缺少磁盘映射信息，无法确认单系统盘配置”，类型无法确定时提示“模板镜像磁盘类型无法确认，已停止创建”；已知数据盘或多盘继续说明单系统盘限制。本修复需更新包含最新 helper 的完整应用；准备失败且尚未提交购买的记录可使用原卡片“重试准备并创建”，无需因此删除共享网络或重新录入凭据。源码修复不自动更新已有安装包。

首次只修复缺省类型时，阿里云及控制层、移动桥接、命令行 helper 四个 Go 包的 race 测试与 vet 通过，Flutter 创建控制器与错误诊断共 37 项通过，静态检查无问题。新增空映射修复覆盖 6 种来源与 5 种空映射形状、两阶段正常链路、基础属性及异常映射阻止写操作；最新完整包验证记录见文末。以上均为源码与模拟响应验证，不能替代真实云创建。

### 创建准备阶段与连接诊断

VPC、交换机准备后，helper 依次完成 SSH 公钥本地检查、共享 VPC 复核、镜像检查、SSH 公钥准备和安全组准备；任一步失败即停止，不提交服务器购买。镜像检查失败时，后续密钥导入和安全组创建均尚未执行，因此仅看到 VPC 而没有密钥对、安全组符合这一执行顺序。

失败显示上述具体阶段及固定原因，连接错误进一步区分域名解析、超时、TLS 证书/域名验证、系统权限、拒绝连接、不可达、中断和取消。Go 与 Flutter 分别校验阶段及原因白名单，不展示原始 URL、查询参数、地址、上游响应或异常文本；未知原因使用固定回退提示。阶段与原因随原卡片保存，重启后仍可核对，重试沿用原记录与已确认的共享网络。辅助程序内部保留原错误类型，用于恢复判断，不把网络失败视为云端明确拒绝。

本轮不带凭据的 HTTPS 连通性探针，对当前模板的 ECS/VPC 官方端点各请求 3 次，均完成证书验证，未携带鉴权的请求收到 HTTP 400；探针没有发送密钥或查询账号资料。结果只说明探针执行时连接可达，不能解释此前应用的具体瞬态错误、证明账号权限或保证后续云请求成功。

### 安全组响应与规则优先级

后续截图显示“安全组准备：阿里云响应异常”，且用户确认安全组与密钥对已经创建。这说明流程已经通过镜像和公钥准备，但安全组存在不等于其规则已校验完成。旧提示同时用于响应体读取失败、响应过大、非预期 HTTP 状态和字段解码失败，截图不足以确定具体分支。

响应诊断现分别报告上述类别；安全组属性读取的字段格式异常进一步区分规则优先级、规则列表、分页标记、归属信息和其它规则内容。所有提示均来自固定白名单，不拼接响应值、原始错误、请求地址或任意字段路径。格式异常仍停止准备和购买，不通过忽略异常规则来继续。

规则优先级只在 `Priority` 字段兼容 JSON 字符串与整数两种等价表示，规范值仍限于 1–100；缺失、null、布尔、容器、小数、指数形式和越界值均拒绝，其它字段继续严格解码。阿里云[官方接口文档](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describesecuritygroupattribute)及官方 SDK 将该字段定义为字符串；数字表示是本次防御性兼容范围，尚未取得截图对应的原始响应，不能据此断言它就是本次线上原因。

补充经过真实 HTTP 解码路径的离线回归，核对已有安全组复用、仅补齐缺少的授权规则、非法响应停止购买与敏感内容过滤。资源归属、规则方向、协议、端口、来源、授权策略及分页完整性校验保持执行；写操作未知结果仍只查询恢复。

## 网络与创建状态

按厂商、账号、地域隔离共享网络账本。VPC 使用专用 `10.8.0.0/16`，每个可用区的交换机从中分配不重叠 `/24`。应用内部复用 `subnet_id` 字段存放阿里云 `vsw-` 交换机标识，对外 API 使用 `VSwitchId`；不会把腾讯云或火山引擎网络 ID 发往阿里云。

先保存创建意图，再调用 `CreateVpc` / `CreateVSwitch`，随后只读查询直到资源可见并可用。超时、响应丢失或应用退出保留未核实意图，重试先查询恢复；同名资源归属或网段不符时停止，不接管已有未知网络。共享安全组归属已确认 VPC，准备操作必须收到该 VPC ID；入站固定 TCP 22/20001、来源 `0.0.0.0/0`，与现有云流程一致。安全组规则及公钥须核验后复用，安全组和公钥创建结果未知时不盲目继续购买。

每轮购买 token 与所选可用区先落入安全存储，再调用 `RunInstances`。只在购买接口明确返回容量不足拒绝时，使用 `DescribeAvailableResource` 查询同地域相同机型的按量候选区；每区最多尝试一次，只改变可用区与交换机，不改变镜像、系统盘、带宽或计费。余额、权限、配额、超时、响应矛盾和未知结果均不触发换区购买。返回实例 ID 仍需查询确认启动与公网地址。

通过管理标签与每轮操作标签恢复未知创建。未查到未知购买不等于确认从未创建，不会据此再次购买。所有查询完整校验分页、归属及响应格式；查询失败不会当作资源不存在。多个独立客户端间不提供分布式创建锁。

### 实例与磁盘的游标分页

用户已反馈云端实例创建成功，但应用显示“创建结果待核实”，释放时显示“阿里云分页查询结果不完整或格式异常”。已确认一项与两种症状一致的接口契约错误：实例和磁盘请求使用 `MaxResults/NextToken`，旧实现却要求 `TotalCount` 非负、跨页不变且等于累计列表长度。阿里云 [DescribeInstances](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeinstances) 与 [DescribeDisks](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describedisks) 明确说明，游标分页下该计数无意义或无效；例如 `TotalCount: 0` 与一条合法实例或磁盘会被旧代码误判为异常。尚未取得截图对应的原始响应，接口契约与离线复现不等于线上修复已验收。

游标分页现仅按 `NextToken` 继续到末页，不用旧计数字段拒绝结果、提前结束或确认资源不存在；安全组列表共用此方式，其官方契约在游标模式下也不返回总数。保留每页最多 50 条、累计最多 4096 条、列表结构、重复条目/游标、空页携带后续游标及游标长度保护。末尾空页保留此前已取得的记录，后续页错误使整次查询失败，不能返回部分结果作为完整资源列表。VPC、交换机、镜像及密钥的页码分页仍严格校验有效总数。

创建后的状态查询与恢复现在保留阿里云固定查询原因，避免把分页或归属错误统一提示为网络/权限问题；仅允许查询阶段的精确错误白名单，原始上游文本和追加内容不写入记录。查询失败保留实例 ID、购买 token 与释放意图，不重复购买、不隐藏资源，也不解除凭据保护。恢复后仍由用户主动释放；释放前继续完整查询磁盘并检查额外磁盘、独立公网 IP 与归属，收到删除受理结果不等于已确认释放。

更新完整应用后，原“创建结果待核实”卡片先点击“查询云端状态”，找回状态和公网地址；原“释放待核实”卡片同样先查询，实例仍在时再点击“释放云服务器”。保留原记录与凭据，不重新创建实例；只有已知实例经完整查询确认不存在后，才从活动列表隐藏。

## 释放与凭证保护

释放前核对准确实例 ID、管理标签、操作标签和按量属性，同时检查云盘及公网关联，避免把外部修改过的资源当作本次标准配置直接删除。系统盘必须符合随实例释放条件；发现额外数据盘、独立 EIP、明确的辅助网卡或其他不满足约束的配置时，停止并提示在云控制台核对，不自动删除外部附属资源。

使用 `DeleteInstance` 精确释放本次已确认的实例；本地先保存释放意图，云端查询确认不存在后才完成释放。API 错误、资源仍在运行或查询未知保留记录。VPC、交换机、安全组及导入公钥作为共享资源保留。网卡字段缺失时不能据此保证不存在未返回的额外关联，检查不构成对所有外部附属资源的完整盘点。管理员另外创建的快照等资源不属于自动清理范围，账单需在云控制台核对。[DeleteInstance 官方释放规则](https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-deleteinstance)

存在未释放/结果未知的实例或未确认的网络意图时，不能移除该厂商凭证或更换 AccessKey ID。已验证凭证不允许直接覆盖，即使 AccessKey ID 相同也需先满足保护条件并移除。存储失败阻止后续购买和释放，不用普通文件绕过安全存储。

## API、权限与通信边界

Go helper 对固定官方区域 HTTPS 端点签名调用 ECS `2014-05-26` 与 VPC `2016-04-28` API，使用 ACS3-HMAC-SHA256。保留系统证书链与域名验证，最低 TLS 1.2，拒绝重定向，不接受模板传入地址或操作名。桌面通过标准输入、Android 通过原生桥接传递凭据，Sisters 不接收云管理凭据。错误只返回固定脱敏消息，不转发原始 URL、请求、云端消息或私钥。[官方签名规范](https://help.aliyun.com/zh/sdk/product-overview/v3-request-structure-and-signature)

写操作只发送一次，使用禁复用的 HTTP/1.1 TLS 连接，连接或响应丢失后交由账本查询恢复，不通过 HTTP 库或 SDK 自动重放购买。仅 9 个明确只读接口（`DescribeImages`、`DescribeKeyPairs`、`DescribeSecurityGroups`、`DescribeSecurityGroupAttribute`、`DescribeInstances`、`DescribeDisks`、`DescribeAvailableResource`、`DescribeVpcs`、`DescribeVSwitches`）遇到已知类型的瞬态传输错误时最多尝试 3 次，间隔 100/200 毫秒；每次重建请求、nonce、时间戳和签名。取消、context 截止、证书失败、业务拒绝、格式异常、响应体读取失败均不自动重试；未列入的操作也不重试。单次请求最多 30 秒、TLS 握手最多 20 秒、整次 helper 操作最多 3 分钟；响应限 2 MiB，拒绝重复 JSON 键及大小写字段别名。实例、磁盘、安全组使用 `MaxResults/NextToken`，VPC、交换机、镜像与密钥使用完整页码查询；响应不完整或分页冲突时停止，不当作资源不存在。安全组授权使用 `Permissions.N.*` 参数。

按实际 RAM 账号策略授权下列能力；这是使用范围说明，尚非真实账号验证过的最小权限策略：

- 身份：`sts:GetCallerIdentity`。
- ECS：`DescribeImages`、`DescribeKeyPairs`、`ImportKeyPair`、`DescribeSecurityGroups`、`CreateSecurityGroup`、`DescribeSecurityGroupAttribute`、`AuthorizeSecurityGroup`、`AuthorizeSecurityGroupEgress`、`DescribeAvailableResource`、`RunInstances`、`DescribeInstances`、`DescribeDisks`、`DeleteInstance`。
- VPC：`DescribeVpcs`、`CreateVpc`、`DescribeVSwitches`、`CreateVSwitch`。
