## 版本内容

- 「配置」集中管理外观和抢票成功通知。「立即刷新」在「配置」左侧。
- Android、macOS 和 Windows 支持本机抢票成功通知，默认关闭。只有本次创建新订单时才提醒。同一订单的重复回报会合并。已有订单可在监控页核对，任务失败或取消时保持静默。
- Android 开启通知后，等待任务结果期间可切换应用或锁屏。通知栏静默展示后台监控状态。任务结束或关闭开关后，后台服务自动停止。
- 定时任务可以设置 0–60000 毫秒的额外延迟，默认 30 毫秒，填 0 按开售时刻执行。Sisters 使用 NTP 校准任务时钟，取不到可用样本时沿用节点系统时间。倒计时与下单时间戳共用任务时钟。[定时任务时钟与运行时复核](../biliTickerBuy运行时.md#定时任务时钟复核)

内嵌 biliTickerBuy 以 **2.15.18** 为基线，定时任务使用来自 #1143 的六个回移文件。平台 HTTPS 校验证书链和域名，订单使用 `standard` 策略，第三方通知配置为空。

## 升级

先在官方订单页核对订单，等待任务结束或手动停止，再用新版 LastOrder 在「机器管理」重新部署所有 Sisters。节点重部署会清空运行记录和应用内付款入口。已保存的账号、任务和云资源记录可继续使用。Android 正式 APK 使用长期发布密钥，可覆盖同签名旧版。

## 验证与限制

本地 Go 竞态测试、`go vet`、Flutter 静态分析、许可清单检查与标签元数据预检通过。Flutter 984 项通过、3 项跳过。打包脚本 135 项通过。锁定依赖下的 Python 运行时回归，桌面 114 项通过、9 项跳过，Android 117 项通过、6 项跳过。

Android 16 arm64 模拟器已用合成订单验证按 Home、熄屏时的通知投递，以及后台服务到期退出。macOS 已通过调试构建和原生通道的参数验证。Windows 主机通知展示、macOS 实际横幅、Android 真机深度休眠及真实票务业务尚待验证。Android 深度休眠或后台服务达到系统时限可能延迟通知。[后台监控说明](../LastOrder/抢票成功通知.md)
