日期：2026-11-14。统一版本 **0.3.0+10**，内嵌 biliTickerBuy **2.15.18**（上游标签 `v2.15.18`，提交 `227ebf73f5af3eec0019984a7cbcb722977453e8`；上游包元数据为 2.15.17）。

## 变更

- **macOS 独立加密存储与单主密钥保护**：改用登录钥匙串单一主密钥保护本地 AES-256-GCM 加密文件（`macos-vault-v1`），会话内复用主密钥，并将元数据、PKI 与导入凭据隔离至独立目录；不读取、迁移或删除旧 macOS 数据。Windows 与 Android 安全存储保持不变。
- **公有云部署接入（腾讯云 CVM、阿里云 ECS、火山引擎 ECS）**：
  - 凭证通过三家官方只读 `GetCallerIdentity` 接口联网验证后才保存；每厂商保留一份、保存后隐藏表单且不可直接覆盖，未释放或待核实云资源保护凭据移除。
  - 按地域与可用区自动创建/复用专用 VPC、子网（或交换机）、固定规则安全组（TCP `22` / `20001` 来源 `0.0.0.0/0`）与本机生成的 RSA 2048 SSH 公钥，支持按量创建、查询恢复、内置 SSH 私钥后台部署与精确释放；建议可用区仅在明确容量或库存不足时查询同地域同机型按量候选区并每区最多尝试一次。
  - 云服务器与关联 Sisters 合并为单张卡片统一展示部署进度、固定脱敏原因与连接状态；云端确认释放后自动移除活动卡片与分发候选（火山引擎同步确认随实例释放的 EIP，阿里云同步核对系统盘与附属资源）。
  - 三家模板格式升级（腾讯云 `schemaVersion: 4`、阿里云/火山引擎 `schemaVersion: 2`），支持明确的 `sshUsername` 及仓库外统一模板工具 `MisakaNetwork-config` 提供的完整 Linux 镜像选择；仓库中已提交的三家公共配置模板已随应用打包。
- **后台 SSH 部署（TOFU）**：保存机器即在后台独立部署并显示阶段与字节估算进度；首次连接自动保存 SHA-256 主机指纹后继续，后续重连/重部署严格校验已保存指纹。
- **任务调度与监控增强**：
  - 任务创建支持 `100`–`60000` 毫秒请求间隔（默认 `1000`），每轮下单尝试上限固定为 `40`；分发前校验 Sisters `supports_request_interval`。
  - 按机器持久化每轮执行意图与结束确认，允许确认成功、失败或取消后使用新执行 ID 再次分发同一任务；分发窗口展示负载并在追加或未确认时提示「多任务风险」。
  - 新增 `OrderPayment` 付款码回显与官方订单详情入口（按账号 UID 与订单号合并多节点订单并在本机内存按需生成二维码），新增「任务监控」已结束记录单条/全部清除及 3 条展开消息展示。
- **界面与维护工具**：机器、账号、任务与监控统一适配宽屏双列/窄屏单列布局，接入三家云厂商官网品牌图标；提供 macOS 本地测试资料清理脚本；重新核查内嵌 `biliTickerBuy` 2.15.18 的接入安全边界；所有模块与平台版本资源统一为 `0.3.0+10`。

## 升级影响与边界

- **macOS 存储隔离（重大变更）**：macOS 首次使用 `0.3.0` 会启用独立 `macos-vault-v1` 目录和登录钥匙串单一主密钥，不读取、迁移或删除旧资料。升级前请先在旧版核对订单、停止或等待远端任务完成，并在旧应用或云平台控制台核对并释放不再使用的云服务器与附属资源；升级后需重新添加并部署机器、登录账号、创建任务、验证公有云凭据与调整外观偏好。Windows 与 Android 不受此目录切换影响。
- **Sisters 重新部署**：安装 `0.3.0` 后须将全部机器上的 Sisters 重新部署为 `0.3.0`（支持请求间隔、付款码回显与独立执行 ID）；升级前先停止或等待现有任务完成，重部署会中断运行任务且不自动恢复。
- **Android 签名延续**：沿用 `0.2.1`/`0.2.3` 长期发布密钥并提高构建号至 `10`；若曾安装 `0.2.0` 等测试签名 APK，仍需卸载旧版再安装（卸载会删除本地数据）。
- **公有云与费用边界**：创建按量云服务器会产生真实云平台费用，关闭 LastOrder 或删除本地记录不会停止远端任务或计费，不再使用时须主动释放并核对云控制台账单及资源；早期开发版旧模板与旧云快照不自动迁移。
- **签名与未实现能力**：macOS 未经 Apple 公证，Windows 未做 Authenticode 签名；Windows Sisters、自动付款、付款码主动刷新、跨节点自动取消、任务重启恢复与证书自动续期仍未实现，Android 后台同步不保证常驻。
