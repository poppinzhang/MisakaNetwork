## 升级影响与边界

- 升级前先停止或等待现有任务完成，升级后重新部署所有 Sisters；重部署会结束正在运行的任务。
- 新建机器默认端口为 `20001`，已有机器继续使用原端口。需要切换时在「重新部署」中修改端口，并放行对应 TCP 端口。
- 现有 schema 2 配置继续读取；缺少外观设置时默认跟随系统。本次升级无需专门重新登录；新设备首次安装仍需登录并配置机器。0.1.0 数据不迁移。
- 从更早版本升级仍应先核对旧任务和已有订单；使用过旧 Android 包导入私钥或证书的设备，应清除应用缓存，详见 [0.1.6 升级记录](0.1.6.md#升级影响与边界)。
- macOS 包使用 ad-hoc 签名，未经 Developer ID 签名与 Apple 公证；Windows 包不含 Authenticode 签名；Android APK 使用测试签名。Android 更换签名可能需要卸载重装。
- Windows Sisters、跨节点自动取消、任务重启恢复、自动证书续期和自动付款尚未实现；Android 后台同步不保证常驻。
- 本地包验证与远程 CI 分别记录；源码及自动化检查不代表真实账号登录、下单或出票已验收。
