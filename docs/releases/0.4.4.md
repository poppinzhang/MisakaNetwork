## 本版改动

- **修复关联商品票档启动与复检异常退出**：当任务配置存在 `link_id`（关联商品票档，其 `project_id` 为子项目 ID）时，内嵌运行时在开始等待与开票前复检阶段沿用建任务时记录的主项目 `is_hot_project` 状态，跳过对不支持子项目 ID 的普通项目详情接口查询，并继续执行原有的 HTTPS 连接预热。
- **修复公有云凭证无法移除的问题**：当「机器管理」列表中已没有该云厂商可见的未释放或待核实云服务器卡片时，允许移除该云厂商的管理凭证或更换旧未验证凭证的访问密钥 ID；已手动清理/隐藏的待核实卡片与遗留的待确认共享网络账本不再阻止解绑。移除凭证确认弹窗在存在已隐藏待核实记录时会提示一并清除，移除成功后同步清除该厂商已隐藏的待核实卡片记录并取消其后台轮询（正在进行的旧恢复查询回包也会安全丢弃）。已释放历史记录与共享网络账本继续保留，若之后重新绑定同一访问密钥仍会先查询复用、不重复建网；机器列表中仍有可见的未释放或待核实云服务器时，继续阻止移除凭证。
- **全面优化界面、错误诊断与说明文案**：
  - 修正公有云提示遗漏阿里云、不存在云记录报错沿用「预览记录」旧称、卡片状态徽章与操作按钮文案混淆（统一为「创建中 / 部署中 / 释放中」）、任务卡片「未结束 0 台」改为「已结束 / 进行中 N 台」、本地运行时超时误提部署、以及添加机器弹窗切至手动连接仍显示自动部署提示等问题。
  - 简化并统一公有云配置、创建确认摘要、释放确认、待核实卡片「隐藏/恢复」、任务分发与监控清理等界面的说明与术语，移除面向普通用户的内部技术词汇；细化 gRPC 错误码中文诊断并提示使用「复制任务」；Windows 启动失败弹窗改为中文；Sisters 状态回报与运行时提示统一为「演出」「开售」「任务已停止」等表达。
  - 重写根目录 `README.md`，并新增图文并茂的 [新手使用指南](../使用指南.md)（含 11 张 LastOrder 界面实截与可选截图回归用例），覆盖安装、本机/远程部署 Sisters、扫码与 Cookie 登录、创建与分发任务、核对订单付款，以及三大云厂商凭证配置与按量创建云服务器全流程。
- **统一版本与全平台重打包**：五种 LastOrder 与五种 Sisters 目标统一为 `0.4.4`；Android `arm64` / `amd64` 的 `versionCode` 分别为 `2017` / `4017`。所有已支持平台与架构均按统一发布约定重新构建。

本版不升级 biliTickerBuy 的版本、固定提交、导入白名单、锁定依赖或运行参数，运行时更新统一版本号、调整少量面向用户的中文提示词，并包含关联商品子项目详情复检的临时缺陷补丁。标准 HTTPS 验证、`standard` 下单策略、默认请求间隔（500 毫秒）、空第三方通知配置与禁止 Web UI/Gradio 的约束保持不变。复核见 [biliTickerBuy 运行时](../biliTickerBuy运行时.md#044-统一版本复核2026-11-21) 与 [关联商品子项目复检适配复核](../biliTickerBuy运行时.md#关联商品子项目复检适配复核2026-11-20)。

## 升级与使用注意

- **重新部署所有 Sisters**：安装 0.4.4 管理端后，在没有活跃抢票任务时将所有受控机器（含 Linux、macOS 和 Windows）重新部署为 `0.4.4`，防止 helper/runtime 版本校验拒绝旧包。重部署会停止该节点正在运行的任务，并清空内存任务历史和付款入口；操作前先核对订单。
- **数据无需重建**：账号、已保存的任务配置、云凭据与资源记录、macOS `macos-vault-v1` 存储格式均与 0.4.3 相同，无需重新登录或重建任务。
- **Android 覆盖安装**：沿用长期发布签名密钥，`versionCode` 从 `2016`/`4016` 递增为 `2017`/`4017`，可覆盖同签名正式版；测试签名 APK 需先卸载。Android 仍只管理任务，不在手机本机运行 Sisters。
- **macOS 与 Windows 签名**：macOS 仍为 ad-hoc 签名、未公证，首次打开新版访问主密钥时可能需要钥匙串授权；Windows 包仍不含 Authenticode 签名。
- **持续运行与订单核对**：关闭 LastOrder 不会停止远程 Sisters；取消和重新部署不能撤销票务平台已创建的订单，仍需在官方平台核对并付款。
