# MisakaNetwork 0.1.0

日期：2026-10-24。构建号：1。内嵌 biliTickerBuy：2.15.17。

交付状态：源码、功能测试、四平台 Sisters 离线包和两种架构 LastOrder 最终安装包均已完成本地构建与核验。未创建 Git Tag、远程 Release 或运行远程 CI。

## 已完成功能

- LastOrder：macOS 15.0+ 管理台，机器部署/重新部署、扫码与 Cookie 登录、场次及购票人选择、任务创建、多机器分发、状态查询与取消。
- Sisters：Linux/macOS amd64/arm64，双向 TLS gRPC、有界并发队列、幂等提交、子进程取消、真实引擎运行状态与结果回传。
- 离线部署：应用内携带四种 Sisters + Python + biliTickerBuy 完整包，SSH 校验主机指纹，自动检测远端平台并部署用户服务。
- 部署验证：通过 SSH 通道建立 mTLS，核验新服务证书与状态，失败时尝试恢复旧版本；不将旧进程占用端口视为新服务成功。
- 凭据保护：用户授权后使用 macOS 登录钥匙串保存 Cookie 和完整任务配置，应用沙盒保持开启；私钥及元数据按私有权限保存。

## 安装包

产物为 `LastOrder-0.1.0-macos-arm64.zip`（176,473,535 字节）和 `LastOrder-0.1.0-macos-amd64.zip`（179,636,180 字节）。每份都包含全部 Linux/macOS Sisters 包，用户只需选择本机适用的 LastOrder 架构。完整 SHA-256 见同目录 `release.json` 和 `SHA256SUMS`。

本地发布目录包含 `SHA256SUMS`、各包独立 `.sha256` 与 `release.json`；校验命令：

```sh
cd dist/0.1.0
shasum -a 256 -c SHA256SUMS
```

## 已知限制

- 使用 ad-hoc 签名，未进行 Developer ID 签名和 Apple 公证；安装时可能需要用户通过系统安全设置确认来源。
- 未使用真实账号完成扫码登录、场次购买或下单；二维码生成成功和自动化测试不等于出票保证。不会自动付款。
- 未在用户真实 SSH 主机上验收。Linux 的 systemd 用户服务需要用户会话可用；退出登录后或开机常驻需要管理员为该账号配置 linger，部署器不会提权。macOS 需要可用的 launchd 用户域。
- 没有跨机器订单互斥和成功后自动取消，用户需自行停止其余任务。同 ID 重复提交不会重新执行已结束任务，重跑需创建新任务。
- Sisters 状态在内存中，重启/重部署会结束任务并清空历史；更新前先取消或等待完成。
- 证书尚未自动续期/撤销；CA 五年、客户端与节点证书一年。务必保留控制端证书目录。
- 网络中断可能使远端恢复步骤无法完成；部署错误需检查远程服务，不承诺失败时必然恢复。
- 上游配置生成要求购票人、收货地址、联系人和电话均完整，包括电子票；缺失时先在平台补齐。
- Windows、Android 不在本次交付范围。
