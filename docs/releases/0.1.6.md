# MisakaNetwork 0.1.6

日期：2026-11-07。统一版本 **0.1.6+6**，内嵌 biliTickerBuy **2.15.18**（上游标签 `v2.15.18`，提交 `227ebf73f5af3eec0019984a7cbcb722977453e8`；上游包元数据仍为 2.15.17）。

**交付状态：五种完整测试包已构建并通过统一核验。** macOS arm64/x64、Windows x64、Android arm64/x64 全部为 0.1.6+6，均内含本轮重建的 Linux/macOS arm64/x64 四种 Sisters 包。Windows 包在原生构建机生成并取回本地；已核对五种应用携带的四份部署包与最终构建输入逐项一致。本轮创建本地 Git Tag `0.1.6`，未推送远程仓库、创建远程 Release 或执行远程 CI。历史 0.1.5 产物保留原样，不包含本轮修复。

## 变更

- 汇集 0.1.5 之后的任务与部署修复：开售时间、同一任务防止再次提交、订单结果稳定性、Windows 中文输出、部署超时与回滚、Linux linger、macOS 后台服务、非 POSIX 登录 shell、直连 mTLS 健康检查、凭据清理和通道复用。
- biliTickerBuy 固定到经过核对的 Git 提交，导入忽略工作区修改，记录发布标签、提交和上游包版本，校验失败保留已有内嵌源码。
- LastOrder、Sisters、helper、runtime、CI 输出路径和 Windows 版本资源统一到 0.1.6+6；发布清单日期集中管理，并增加跨语言版本一致性回归测试。
- 补齐 Windows 专用 Python 运行时与构建工具的传递依赖锁定；上游导入测试固定 UTF-8/LF 与 Git 换行配置，消除 Windows 默认换行造成的测试差异。
- 修复 Windows 主机准备 Android 源码时未拒绝盘根路径的问题；统一校验 POSIX 清单，拒绝盘符、反斜杠、点目录及解析后逃逸。补充 22 种非法路径和父级链接用例，正常清单的源码准备结果逐字节不变。
- Windows 与 Android 管理台沿用现有实现；所有应用完整携带四种 Sisters 部署包，安装与远程部署无需额外下载运行时。
- 修复上游配置与 Cookie 数据库句柄未关闭造成的 Windows 运行时退出失败；Windows 便携包携带并验证 x64 MSVC 发布运行库。
- 本地存储增加可注入的权限操作，默认仍执行原生权限保护；验证先保护临时文件再替换、权限失败保留原状态，消除 Windows 单测对未打包 helper 的依赖。

## 安装与功能验收

macOS 按芯片架构选择 ZIP，完整解压后运行 `LastOrder.app`。Windows x64 完整解压 ZIP 后运行 `LastOrder/LastOrder.exe`，不要只复制 EXE。Android 16 及以上通常选择 arm64 APK；x64 APK 用于对应架构的设备或模拟器，通过系统安装器安装。

后续三端功能验收可按以下顺序进行，并分别记录真实设备与系统版本：

1. 启动应用，确认版本 0.1.6；验证账号登录、退出重开后的安全存储读取及登录失效提示。
2. 添加 Linux 或 macOS 机器，核对 SSH 指纹，验证首次部署、直连 mTLS 状态与重新部署。
3. 查询演出、票档、购票人和地址，创建带北京时间开售时间的任务；检查跨页面与重启后的显示。
4. 在明确要执行真实业务时分发任务，验证等待开票、进度、取消和结果回传；同一任务不应重复提交给已接收的机器。

自动化检查没有执行真实账号登录或下单，这些操作的业务结果需由本轮功能验收补充。

## 升级影响与边界

- 更新前先停止或等待已有任务完成，升级后重新部署所有 Sisters；旧服务不能接收新版定时任务，重部署会结束正在运行的任务。
- 0.1.1 起的 schema 2 存储模型保持不变；0.1.0 数据不迁移。新设备首次安装需登录并配置机器，不自动跨设备复制 Cookie、私钥或 CA。
- 从旧包升级时，旧任务不会自动补齐开售时间或历史分发记录；重新部署也会清空远端任务记录。先核对平台订单和已有执行情况，清理旧任务；确需再次执行时重新创建任务并设置开售时间，不能把读取旧状态视为已具备完整防重复提交保障。
- 使用过旧 Android 包导入私钥或证书的设备，请在系统设置中清除 LastOrder **缓存**，删除旧选择器可能残留的明文副本；无需为此清除应用数据。新版会主动清理本轮导入缓存与未被引用的凭据副本。
- macOS 使用 ad-hoc 签名，未做 Developer ID 签名与公证；Windows 包不含 Authenticode 签名；Android 使用测试签名，切换签名可能需要卸载重装并重新登录。
- Android 仅支持 Android 16 / API 36 及以上，后台同步不保证常驻。Windows 仅支持 Windows 10+ x64；macOS 最低 15.0。
- Sisters 只支持 Linux/macOS x64/arm64，Windows Sisters 尚未实现。跨节点自动取消、任务重启恢复、证书自动续期与自动付款仍不提供。

实现与构建细节见 [Windows 与 Android](../LastOrder/Windows与Android.md)、[biliTickerBuy 运行时](../biliTickerBuy运行时.md) 和 [打包与发布](../打包与发布.md)。
