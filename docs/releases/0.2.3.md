日期：2026-11-12。统一版本 **0.2.3+9**，内嵌 biliTickerBuy **2.15.18**（上游标签 `v2.15.18`，提交 `227ebf73f5af3eec0019984a7cbcb722977453e8`；上游包元数据为 2.15.17）。本版不调整上游快照、运行时依赖、导入白名单或平台请求参数。

**发布准备状态：待本轮完整构建与发布验证。** 本版发布为正式 Release，并设为 Latest，不使用 Pre-Release。1.0.0 前仍为早期研发版本。实际交付以 [0.2.3 Release](https://github.com/poppinzhang/MisakaNetwork/releases/tag/0.2.3) 的公开状态与资产为准；不能用旧版本构建结果代替本版验证。

- 回归覆盖草稿 Tag 查询 404、列表尚未更新、创建或读取失败、非法 ID、状态变化、上传失败与资产不一致。
- 包含 0.2.1 的统一应用图标、关于与离线许可、手机首页布局、用户文档和全平台发布 CI 改进，详情见 [0.2.1 变更记录](0.2.1.md#变更)。

## 安装包

全部构建和发布核验通过后，[0.2.3 Release 下载页](https://github.com/poppinzhang/MisakaNetwork/releases/tag/0.2.3) 提供以下五种完整包，另附每包 `.sha256`、联合 `SHA256SUMS` 和 `release.json`。每份应用均携带同版本 Linux/macOS arm64/x64 四种 Sisters 离线部署包。

| 文件 | 平台与签名 |
| --- | --- |
| `LastOrder-0.2.3-macos-arm64.zip` | macOS 15+ Apple 芯片；ad-hoc 签名，未公证 |
| `LastOrder-0.2.3-macos-amd64.zip` | macOS 15+ Intel；ad-hoc 签名，未公证 |
| `LastOrder-0.2.3-windows-amd64.zip` | Windows 10+ x64；未含 Authenticode 签名 |
| `LastOrder-0.2.3-android-arm64.apk` | Android 16 / API 36+ arm64；长期发布密钥签名 |

macOS 解压后打开 `LastOrder.app`；Windows 完整解压后打开 `LastOrder/LastOrder.exe`，不要只复制 EXE；Android 通常选择 arm64 APK。Sisters 包已内嵌，无需单独下载。

## 升级影响与边界

- 升级前核对订单并停止或等待现有任务完成；安装新 LastOrder 后重新部署全部 Sisters。重部署会中断任务，不自动恢复。
- 现有 schema 2 配置、主题和显式端口继续使用，桌面端无需因本次升级重新登录。新设备仍需添加机器并登录；0.1.0 数据不迁移。
- 从 0.2.0 等测试签名 Android APK 升级时，需要卸载旧版再安装，卸载会删除本地数据，因此需重新登录、添加机器和创建任务。曾安装同一长期密钥签名的 0.2.1 CI 包时，本版沿用该密钥并提高版本号。
- macOS 未经 Apple 公证，Windows 未做 Authenticode 签名；正式 Release 标识不改变这些签名状态或业务验证范围。
- 一台机器成功后不会自动停止其他机器；关闭管理台或删除本地记录不会取消远程任务。
- Windows Sisters、自动付款、跨节点自动取消、任务重启恢复与证书自动续期仍未实现；Android 后台同步不保证常驻。
